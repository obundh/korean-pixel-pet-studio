# 초보자용 완성 펫 예제

이 폴더는 설명만 있는 갤러리가 아니라, PixelPet Studio의 실제 제작 흐름을 확인하기 위한 예제 모음입니다.

- 공개 가능한 오리지널 마스코트 3종
- 권리 확인 전에는 로컬에서만 만들어야 하는 RRA 파비 recipe 1종

모든 예제는 `examples/beginner-pets/<id>/` 아래에 둡니다.

## 공개 오리지널 샘플 3종

| 샘플 | 캐릭터 | 폴더 |
|---|---|---|
| Haeori | 햇살 수달 | [`haeori-sun-otter`](beginner-pets/haeori-sun-otter/) |
| Mongle | 구름 곰 | [`mongle-cloud-bear`](beginner-pets/mongle-cloud-bear/) |
| Toto | 새싹 거북 | [`toto-sprout-turtle`](beginner-pets/toto-sprout-turtle/) |

세 캐릭터는 이 저장소의 제작 흐름을 검증하기 위해 새로 만든 공개 오리지널 예시입니다.

## 3분 안에 공개 샘플 실행하기

1. `examples/beginner-pets/`를 엽니다.
2. 위 표에서 공개 오리지널 샘플 하나를 고릅니다.
3. 해당 폴더의 `.pixelpet` 파일을 누릅니다.
4. GitHub 파일 화면 오른쪽 위의 **Download raw file** 버튼으로 컴퓨터에 저장합니다. 화면에 보이는 긴 JSON 글자를 직접 복사하지 마세요.
5. PixelPet Studio를 실행합니다.
6. 위쪽 **불러오기**를 누릅니다.
7. 저장한 `.pixelpet` 파일을 선택합니다.
8. **움직임 확인**에서 대기 애니메이션을 봅니다.
9. **펫 완성 → 데스크톱에서 실행**을 누릅니다.

정상이라면 투명한 펫이 화면 위에 나타납니다. 앱으로 돌아가 **데스크톱 펫 종료**를 누르면 종료됩니다.

## 공개 오리지널 샘플에 들어 있는 파일

세 샘플은 같은 구조를 사용합니다. `<id>`에는 표의 폴더 이름이 들어갑니다.

```text
examples/beginner-pets/<id>/
├── README.md                 # 미리보기, 가장 짧은 실행법과 실제 앱 경로
├── PROMPTS.md                # 실제 imagegen 프롬프트와 첨부 순서
├── SOURCE_AND_RIGHTS.md      # 오리지널 제작 출처와 공개 범위
├── source.png                # 공개 가능한 오리지널 마스코트 레퍼런스
├── pixel-master-chroma.png   # 빠른 만들기에 넣은 픽셀 기준 이미지
├── generated/
│   ├── idle-01.png
│   ├── idle-02.png
│   ├── idle-03.png
│   └── idle-04.png
├── app-preview.png           # 실제 앱 미리보기 캡처
├── <id>.pixelpet             # 앱에서 바로 불러오는 프로젝트
├── <id>-spritesheet.png      # 앱에서 내보낸 스프라이트시트
└── run-log.json              # 실행 단계, 캔버스, 모델과 파일 해시 기록
```

`pixel-master-chroma.png`의 단색 배경은 의도된 입력입니다. PixelPet Studio가 이 배경을 로컬에서 제거하는 과정을 검증합니다. `.pixelpet`에는 이미지 데이터가 함께 들어 있어 파일만 옮겨도 다시 열 수 있습니다.

## “프로그램으로 만들었다”의 범위

오리지널 픽셀 기준 이미지는 생성형 AI에서 만들 수 있습니다. 그 이후 아래 작업은 PixelPet Studio에서 수행하고 `run-log.json`에 기록합니다.

1. 픽셀 이미지 가져오기
2. **이미지 한 장으로 자동 완성** 카드의 **이미지 한 장 고르기** 실행
3. 기기 내 자동 배경 제거
4. 단색 배경의 남은 경계색 제거, 색 번짐 보정과 픽셀용 투명도 정리
5. 선택한 스타일의 픽셀 캔버스로 정규화. 기본 예시는 64×64, 일부 스타일은 96×96
6. 대기(`idle`) 프레임 4장 구성
7. 움직임 확인
8. `.pixelpet` 프로젝트 저장
9. 스프라이트시트 PNG 내보내기
10. 데스크톱 펫 실행 확인

새로운 걷기나 점프 포즈가 있는 샘플은 AI에서 포즈별 이미지를 한 장씩 만든 뒤 앱의 정식 프레임 슬롯에 넣습니다.

## 내 샘플로 연습하는 순서

공개 오리지널 샘플의 `pixel-master-chroma.png` 한 장만 내려받아 다음을 따라 해도 됩니다.

1. 새 PixelPet Studio 프로젝트를 엽니다.
2. **배경 제거** 단계로 이동합니다.
3. **이미지 한 장으로 자동 완성** 카드에서 **이미지 한 장 고르기**를 누릅니다.
4. 기준 픽셀 이미지 한 장을 선택합니다.
5. 대기 프레임이 `4/4`로 채워졌는지 확인합니다.
6. **움직임 확인**에서 6~8 FPS와 3× 배율을 시험합니다.
7. **펫 완성 → 프로젝트 저장**을 누릅니다.

제공된 `.pixelpet`과 직접 만든 결과가 조금 달라도 정상입니다. 배율이나 FPS 설정에 따라 보이는 속도와 크기가 달라질 수 있습니다.

## RRA 파비는 왜 파일이 없나요?

RRA는 국립전파연구원 홈페이지를 뜻합니다. 파비 마스코트는 국립전파연구원의 공식 자료를 참고하되, 다음 권리 경계를 적용합니다.

- 공식 마스코트 페이지: [국립전파연구원 · 마스코트](https://www.rra.go.kr/ko/intro/character.do)
- 공식 기관 홈페이지: [국립전파연구원](https://www.rra.go.kr/ko/index.do)
- 공식 저작권 안내: [국립전파연구원 · 저작권정책](https://www.rra.go.kr/ko/include/copyright.do)
- 확인 기준일: 2026-07-15
- 공식 페이지는 파비 소개와 PNG 이모티콘 다운로드를 제공하지만, 확인한 페이지에는 재사용 조건을 정하는 확인 가능한 공공누리(KOGL) 표시가 없었습니다.
- 홈페이지에서 볼 수 있다는 사실만으로 복제, AI 변형, 재배포가 허용되는 것은 아닙니다.
- 이 저장소의 MIT 라이선스는 파비 원본과 파생 이미지에 적용되지 않습니다.

따라서 `examples/beginner-pets/rra-pavi/`에는 다음 내용만 둘 수 있습니다.

- 공식 출처 링크
- 사용자가 권한을 확인한 뒤 로컬에서 따라 할 recipe
- 프롬프트의 일반 구조와 앱 버튼 순서
- 공개 파일이 없다는 검증 메모

다음 자료는 권리자의 명시적 사전 허락을 받기 전까지 공개 저장소에 커밋하지 않습니다.

- 홈페이지에서 내려받거나 캡처한 파비 원본
- AI가 픽셀화하거나 포즈를 바꾼 파비 이미지
- 파비 이미지가 포함된 `.pixelpet` 파일
- Base64 이미지가 들어 있는 JSON
- 파비 스프라이트시트, 썸네일, GIF, 앱 캡처

`.pixelpet`과 JSON은 눈에 바로 이미지가 보이지 않아도 이미지 데이터를 포함할 수 있으므로 공개하면 안 됩니다.

국립전파연구원의 저작권정책은 공공누리 제1유형 표시가 붙은 자료의 이용조건을 별도로 설명하며, 그렇지 않은 자료는 담당자와 사전 협의하도록 안내합니다. 2026-07-15 확인 당시 권리 문의는 정보운영과 홈페이지 담당 `061-338-4911` 또는 대표번호 `061-338-4567`로 할 수 있었습니다. 연락처가 바뀔 수 있으므로 실제 요청 전 공식 홈페이지에서 다시 확인하세요.

## 권한을 받은 사용자의 로컬 파비 recipe

다음 과정은 권리자가 사용·변형을 허락했거나 본인에게 별도 권한이 있을 때만 로컬에서 진행합니다.

1. [공식 마스코트 페이지](https://www.rra.go.kr/ko/intro/character.do)에서 출처 URL과 확인 날짜를 기록합니다.
2. 허락의 범위가 개인 시연, 기관 내부 사용, 공개 배포 중 어디까지인지 기록합니다.
3. 허가를 받았다면 공식 페이지의 [정면 PNG 다운로드](https://www.rra.go.kr/FileDownSvl?file_type=notice&file_parentseq=5672&file_seq=1)처럼 출처가 분명한 원본만 내 컴퓨터의 저장소 밖 폴더에 저장합니다.
4. 일반 일러스트라면 [AI 생성 가이드](../docs/beginner/CREATE_WITH_AI.md)에 따라 기준 픽셀 마스터를 만듭니다.
5. 픽셀 이미지 한 장이 준비되면 앱의 **이미지 한 장으로 자동 완성** 카드에서 **이미지 한 장 고르기**를 실행합니다.
6. 배경 제거, 선택 스타일 크기 정규화와 대기 4프레임 결과를 확인합니다.
7. 프로젝트도 저장소 밖 로컬 폴더에 저장합니다.
8. 권리자가 공개를 별도로 허락하지 않았다면 스크린샷도 GitHub, 메신저나 발표 자료에 올리지 않습니다.

`rra-pavi` recipe 폴더에 결과 이미지가 없다는 것은 누락이 아니라 의도적인 권리 보호 조치입니다.

공식 출처, 권리 문의 문안, 로컬 기준 픽셀 프롬프트와 앱 버튼 순서는 [RRA 파비 로컬 전용 recipe](beginner-pets/rra-pavi/README.md)에 정리했습니다.

## 새 샘플을 추가할 때

1. 캐릭터가 오리지널인지 또는 공개 권한이 있는지 확인합니다.
2. 샘플 설명이나 권리 문서에 제작자, 생성 방식, 외부 입력, 허용 범위를 기록합니다.
3. 생성형 AI를 사용했다면 실제 프롬프트와 첨부 순서를 재현 가능한 형태로 기록합니다.
4. `run-log.json`에 앱에서 실행한 단계, FPS, 배율과 결과 파일 해시를 기록합니다.
5. `.pixelpet`을 새로 불러와 재생되는지 확인합니다.
6. 이미지가 포함된 파일 전체를 공개해도 되는지 마지막으로 확인합니다.

처음부터 새 펫을 만드는 전체 과정은 [처음 시작하기](../START_HERE.md), 세부 화면은 [앱 따라 하기](../docs/beginner/APP_WALKTHROUGH.md)를 참고하세요.
