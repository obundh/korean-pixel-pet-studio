# 초보자용 완성 펫 예제

이 폴더는 설명만 있는 갤러리가 아니라, PixelPet Studio의 실제 제작 흐름을 확인하기 위한 예제 모음입니다.

- 공개 가능한 오리지널 마스코트 3종
- 권리 확인 전에는 로컬에서만 만들어야 하는 RRA 파비 recipe 1종

모든 예제는 `examples/beginner-pets/<id>/` 아래에 둡니다.

## 공개 오리지널 샘플 3종

| 샘플 | 캐릭터 | 폴더 |
|---|---|---|
| Haeori | 햇살 수달 | [`haeori-sun-otter`](beginner-pets/haeori-sun-otter/) |
| Mongle | 구름 곰 | [`mongle-cloud-bear`](beginner-pets/mongle-cloud-bear/) |
| Toto | 새싹 거북 | [`toto-sprout-turtle`](beginner-pets/toto-sprout-turtle/) |

세 캐릭터는 이 저장소의 제작 흐름을 검증하기 위해 기획하고 생성한 공개 프로젝트 예시입니다. 기록된 제작 과정에서는 외부 기관 마스코트나 기존 캐릭터 이미지를 입력하지 않았지만, 이것이 독창성·독점성·비침해를 보증하는 것은 아닙니다. 정확한 범위는 각 폴더의 `SOURCE_AND_RIGHTS.md`와 루트 [`ASSET_LICENSE.md`](../ASSET_LICENSE.md)를 확인하세요.

## 3분 안에 공개 샘플 실행하기

1. `examples/beginner-pets/`를 엽니다.
2. 위 표에서 공개 오리지널 샘플 하나를 고릅니다.
3. 해당 폴더의 `.pixelpet` 파일을 누릅니다.
4. GitHub 파일 화면 오른쪽 위의 **Download raw file** 버튼으로 컴퓨터에 저장합니다. 화면에 보이는 긴 JSON 글자를 직접 복사하지 마세요.
5. PixelPet Studio를 실행합니다.
6. 위쪽 **불러오기**를 누릅니다.
7. 저장한 `.pixelpet` 파일을 선택합니다.
8. **움직임 확인**에서 대기 애니메이션을 봅니다.
9. **펫 완성 → 데스크톱에서 실행**을 누릅니다.

정상이라면 투명한 펫이 화면 위에 나타납니다. 앱으로 돌아가 **데스크톱 펫 종료**를 누르면 종료됩니다.

## 공개 오리지널 샘플에 들어 있는 파일

세 샘플은 같은 구조를 사용합니다. `<id>`에는 표의 폴더 이름이 들어갑니다.

```text
examples/beginner-pets/<id>/
├── README.md                 # 미리보기, 가장 짧은 실행법과 실제 앱 경로
├── PROMPTS.md                # 실제 imagegen 프롬프트와 첨부 순서
├── SOURCE_AND_RIGHTS.md      # 생성 출처, 외부 입력 여부와 공개 범위
├── source.png                # AI로 만든 일반 마스코트 레퍼런스
├── pixel-master-chroma.png   # 캐릭터 정체성의 픽셀 기준 마스터
├── ai-idle-sheet-chroma.png  # 왼쪽부터 실제 대기 포즈 4칸이 있는 AI 시트
├── generated/
│   ├── idle-01.png
│   ├── idle-02.png
│   ├── idle-03.png
│   └── idle-04.png
├── app-preview.png           # 실제 앱 미리보기 캡처
├── <id>.pixelpet             # 앱에서 바로 불러오는 프로젝트
├── <id>-spritesheet.png      # 앱에서 내보낸 스프라이트시트
└── run-log.json              # 처리 품질, 실제 재생 순서와 파일 해시 기록
```

`ai-idle-sheet-chroma.png`는 가로 한 줄에 같은 캐릭터의 서로 다른 포즈 네 장이 들어 있는 입력입니다. 세 공개 시트는 모두 `2172×724`이고, 앱은 왼쪽부터 `543×724` 크기의 네 칸으로 정확히 나눕니다. 마젠타 단색 배경은 최종 배경이 아니라 앱의 직접 크로마 정리를 시험하기 위한 입력입니다. `.pixelpet`에는 이미지 데이터가 함께 들어 있어 파일만 옮겨도 다시 열 수 있습니다.

## “프로그램으로 만들었다”의 범위

생성형 AI는 캐릭터 기준 마스터와 실제로 자세가 다른 대기 포즈 네 장을 만듭니다. 그 이후 아래 작업은 PixelPet Studio에서 수행하고 `run-log.json`에 기록합니다.

1. **프레임 가져오기 → 포즈 시트 한 장 가져오기**로 `ai-idle-sheet-chroma.png` 선택
2. 앱이 가로 시트를 왼쪽부터 대기 프레임 `0, 1, 2, 3`으로 균등 분할
3. **이 동작 한 번에 정리** 실행
4. 균일한 마젠타 배경은 IMG.LY 분할 모델을 거치지 않고 직접 제거
5. 어두워진 마젠타 테두리까지 HSV·색 방향으로 찾고, 투명 배경과 맞닿은 잔색만 가까운 정상 캐릭터 색으로 복원한 뒤 hard alpha로 정리
6. 머리·몸통처럼 넓고 안정적인 가로 행을 기준으로 생성 과정의 작은 좌우 드리프트만 상한 안에서 보정하고, 전체 포즈의 합집합 범위와 공통 배율·최종 배치를 사용해 `64×64`로 정렬
7. 전체 캐릭터 찌그러뜨림, 위치·발 기준선 점프, 반투명 픽셀과 크로마 잔색 검사
8. **움직임 확인**과 실제 데스크톱 펫 창에서 `0 → 1 → 2 → 3 → 0` 순서 및 `4 FPS` 재생 확인
9. `.pixelpet` 프로젝트와 스프라이트시트 PNG 내보내기

걷기나 점프도 같은 방식으로 개별 포즈 여러 장 또는 한 줄 포즈 시트를 가져온 뒤 해당 동작 전체를 한 번에 정리할 수 있습니다.

### 빠른 모드는 왜 사용하지 않았나요?

**이미지 한 장으로 자동 완성**은 한 장의 픽셀 이미지를 같은 크기로 유지한 채 `0px → 위로 1px → 위로 1px → 0px`만 이동시키는 `4 FPS` 무왜곡 bob입니다. 예전처럼 몸 전체를 늘이거나 납작하게 만들지는 않지만, 팔·눈·꼬리 같은 부위가 실제로 변하는 포즈 애니메이션도 아닙니다.

따라서 정지 이미지가 앱에서 뜨는지 빨리 시험할 때는 유용하지만, 이 공개 샘플 3종의 제작 경로에는 사용하지 않았습니다.

## 내 샘플로 연습하는 순서

공개 샘플의 `ai-idle-sheet-chroma.png`를 내려받아 실제 제작 경로를 그대로 연습할 수 있습니다.

1. 새 PixelPet Studio 프로젝트를 엽니다.
2. **생성 가이드**에서 `64×64` 스타일을 선택합니다.
3. **프레임 가져오기**에서 대기 동작을 선택합니다.
4. **포즈 시트 한 장 가져오기**를 눌러 시트 파일을 선택합니다.
5. 대기 슬롯이 왼쪽부터 `4/4`로 채워졌는지 확인합니다.
6. **이 동작 한 번에 정리**를 누릅니다.
7. 상태 안내에 `64 × 64 공통 좌표`와 `단색 배경 4장 직접 정리`가 표시되는지 확인합니다.
8. **움직임 확인**에서 `4 FPS`, 화면 배율 `3×`로 재생합니다.
9. **펫 완성 → 프로젝트 저장**을 누릅니다.

제공된 `.pixelpet`과 직접 만든 결과의 UUID나 저장 시각이 달라도 정상입니다. 같은 시트를 사용했다면 포즈 순서, `64×64` 캔버스와 공통 발 기준선은 같아야 합니다.

## RRA 파비는 왜 파일이 없나요?

RRA는 국립전파연구원 홈페이지를 뜻합니다. 파비 마스코트는 국립전파연구원의 공식 자료를 참고하되, 다음 권리 경계를 적용합니다.

- 공식 마스코트 페이지: [국립전파연구원 · 마스코트](https://www.rra.go.kr/ko/intro/character.do)
- 공식 기관 홈페이지: [국립전파연구원](https://www.rra.go.kr/ko/index.do)
- 공식 저작권 안내: [국립전파연구원 · 저작권정책](https://www.rra.go.kr/ko/include/copyright.do)
- 확인 기준일: 2026-07-15
- 공식 페이지는 파비 소개와 PNG 이모티콘 다운로드를 제공하지만, 확인한 페이지에는 재사용 조건을 정하는 확인 가능한 공공누리(KOGL) 표시가 없었습니다.
- 홈페이지에서 볼 수 있다는 사실만으로 복제, AI 변형, 재배포가 허용되는 것은 아닙니다.
- 이 저장소의 코드·오리지널 자산 라이선스는 파비 원본과 파생 이미지에 적용되지 않습니다.

따라서 `examples/beginner-pets/rra-pavi/`에는 다음 내용만 둘 수 있습니다.

- 공식 출처 링크
- 사용자가 권한을 확인한 뒤 로컬에서 따라 할 recipe
- 프롬프트의 일반 구조와 앱 버튼 순서
- 공개 파일이 없다는 검증 메모

다음 자료는 권리자의 명시적 사전 허락을 받기 전까지 공개 저장소에 커밋하지 않습니다.

- 홈페이지에서 내려받거나 캡처한 파비 원본
- AI가 픽셀화하거나 포즈를 바꾼 파비 이미지
- 파비 이미지가 포함된 `.pixelpet` 파일
- Base64 이미지가 들어 있는 JSON
- 파비 스프라이트시트, 썸네일, GIF, 앱 캡처

`.pixelpet`과 JSON은 눈에 바로 이미지가 보이지 않아도 이미지 데이터를 포함할 수 있으므로 공개하면 안 됩니다.

국립전파연구원의 저작권정책은 공공누리 제1유형 표시가 붙은 자료의 이용조건을 별도로 설명하며, 그렇지 않은 자료는 담당자와 사전 협의하도록 안내합니다. 2026-07-15 확인 당시 권리 문의는 정보운영과 홈페이지 담당 `061-338-4911` 또는 대표번호 `061-338-4567`로 할 수 있었습니다. 연락처가 바뀔 수 있으므로 실제 요청 전 공식 홈페이지에서 다시 확인하세요.

## 권한을 받은 사용자의 로컬 파비 recipe

다음 과정은 권리자가 사용·변형을 허락했거나 본인에게 별도 권한이 있을 때만 로컬에서 진행합니다.

1. [공식 마스코트 페이지](https://www.rra.go.kr/ko/intro/character.do)에서 출처 URL과 확인 날짜를 기록합니다.
2. 허락의 범위가 개인 시연, 기관 내부 사용, 공개 배포 중 어디까지인지 기록합니다.
3. 허가를 받았다면 공식 페이지의 [정면 PNG 다운로드](https://www.rra.go.kr/FileDownSvl?file_type=notice&file_parentseq=5672&file_seq=1)처럼 출처가 분명한 원본만 내 컴퓨터의 저장소 밖 폴더에 저장합니다.
4. 일반 일러스트라면 [AI 생성 가이드](../docs/beginner/CREATE_WITH_AI.md)에 따라 기준 픽셀 마스터를 만듭니다.
5. 같은 기준 마스터를 정체성 레퍼런스로 사용해 실제 포즈 네 장이 있는 가로 시트를 만듭니다.
6. 앱의 **포즈 시트 한 장 가져오기 → 이 동작 한 번에 정리**를 실행합니다.
7. `64×64`, `4 FPS` 결과와 실제 프레임 순서를 확인합니다.
8. 프로젝트도 저장소 밖 로컬 폴더에 저장합니다.
9. 권리자가 공개를 별도로 허락하지 않았다면 스크린샷도 GitHub, 메신저나 발표 자료에 올리지 않습니다.

`rra-pavi` recipe 폴더에 결과 이미지가 없다는 것은 누락이 아니라 의도적인 권리 보호 조치입니다.

공식 출처, 권리 문의 문안, 로컬 기준 픽셀 프롬프트와 앱 버튼 순서는 [RRA 파비 로컬 전용 recipe](beginner-pets/rra-pavi/README.md)에 정리했습니다.

## 새 샘플을 추가할 때

1. 모든 입력 이미지와 결과를 공개할 권한이 있는지 확인합니다. “오리지널”이라는 자체 판단만으로 권리 확인을 대신하지 않습니다.
2. 샘플 설명이나 권리 문서에 제작자, 생성 방식, 외부 입력, 허용 범위를 기록합니다.
3. 생성형 AI를 사용했다면 실제 프롬프트와 첨부 순서를 재현 가능한 형태로 기록합니다.
4. `run-log.json`에 포즈 시트 해시, 공통 정렬, 품질 검사, FPS, 실제 순환 재생과 결과 파일 해시를 기록합니다.
5. `.pixelpet`을 새로 불러와 `0 → 1 → 2 → 3 → 0` 순서로 재생되는지 확인합니다.
6. 전체 비트맵 변형, 발 기준선 점프, 반투명 픽셀과 배경색 잔상이 없는지 확인합니다.
7. 이미지가 포함된 파일 전체를 공개해도 되는지 마지막으로 확인합니다.

처음부터 새 펫을 만드는 전체 과정은 [처음 시작하기](../START_HERE.md), 세부 화면은 [앱 따라 하기](../docs/beginner/APP_WALKTHROUGH.md)를 참고하세요.
