## 제작 출처

Haeori는 2026-07-15 PixelPet Studio 초보자 예제를 위해 새로 기획하고 생성한 마스코트 예제입니다.

- `source.png`: 텍스트 프롬프트만 사용해 Codex 내장 imagegen으로 생성
- `pixel-master-chroma.png`: `source.png`와 이 저장소의 정체성 중립 `soft-cluster-16` 스타일 레퍼런스를 사용해 내장 imagegen으로 변환
- `ai-idle-sheet-chroma.png`: `pixel-master-chroma.png`를 정체성 기준으로 사용해 내장 imagegen으로 실제 대기 포즈 4장을 생성
- `generated/idle-*.png`: PixelPet Studio가 포즈 시트를 4등분하고, flat chroma 제거와 공통 좌표 정렬을 적용해 생성
- `.pixelpet`, 스프라이트시트, `app-preview.png`: PixelPet Studio가 저장·내보내기·캡처

실제 imagegen 프롬프트는 [`PROMPTS.md`](PROMPTS.md), 앱 처리 증거와 파일 해시는 [`run-log.json`](run-log.json)에 있습니다.

생성에는 Codex에서 제공된 OpenAI 이미지 생성 기능을 사용했습니다. 생성 서비스의 이용은 생성에 사용한 계정에 적용되는 OpenAI 약관을 따르며, 서비스 약관상 출력 권리의 귀속과 별개로 출력은 고유하지 않을 수 있습니다. 공급자 약관과 CC BY 적용 범위의 한계는 루트 [`ASSET_LICENSE.md`](../../../ASSET_LICENSE.md)에 기록합니다.
