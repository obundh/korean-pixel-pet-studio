# Mongle 출처와 권리 기록

## 공개 상태

- 샘플 ID: `mongle-cloud-bear`
- 공개 여부: `public: true`
- 외부 기관·브랜드 마스코트: 아님
- 특정 게임, 프랜차이즈 또는 현존 작가의 캐릭터: 아님

## 제작 출처

Mongle은 2026-07-15 PixelPet Studio 초보자 예제를 위해 새로 기획한 오리지널 생성형 마스코트입니다.

- `source.png`: 텍스트 프롬프트만 사용해 Codex 내장 imagegen으로 생성
- `pixel-master-chroma.png`: `source.png`와 이 저장소의 오리지널 `bold-outline-32` 스타일 레퍼런스를 사용해 내장 imagegen으로 변환
- `generated/idle-*.png`: PixelPet Studio 빠른 만들기가 생성
- `.pixelpet`, 스프라이트시트, `app-preview.png`: PixelPet Studio가 저장·내보내기·캡처

실제 imagegen 프롬프트는 [`PROMPTS.md`](PROMPTS.md), 앱 처리 증거와 파일 해시는 [`run-log.json`](run-log.json)에 있습니다.

## 외부 입력 여부

캐릭터 생성에 외부 기관 마스코트, 사용자 사진, 상표, 제3자 작가 이미지나 기존 캐릭터 레퍼런스를 사용하지 않았습니다. 픽셀 변환에 사용한 스타일 레퍼런스 역시 이 저장소를 위해 만든 정체성 중립 오리지널 자산입니다.
