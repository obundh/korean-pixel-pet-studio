# PixelPet Studio v0.1.0

마스코트 레퍼런스를 투명 배경의 애니메이션 데스크톱 픽셀 펫으로 조립하는 첫 공개 버전입니다.

## 다운로드

- Windows x64
  - `PixelPet-Studio-Setup-0.1.0-x64.exe`: 설치형
  - `PixelPet-Studio-Portable-0.1.0-x64.exe`: 설치 없는 포터블형
- macOS
  - `PixelPet-Studio-0.1.0-arm64.dmg` / `.zip`: Apple Silicon
  - `PixelPet-Studio-0.1.0-x64.dmg` / `.zip`: Intel

## 포함 기능

- GPT/Gemini 한·영 템플릿과 완전 치환된 프레임 프롬프트 560개
- 오리지널 예시 펫 5종, 스타일 레퍼런스 5장, 포즈 레퍼런스 28장
- 드래그 앤 드롭 프레임 슬롯과 `idle`, `walk`, `jump`, `sleep`, `reaction` 미리보기
- 로컬 IMG.LY IS-Net 배경 제거
- `.pixelpet` 프로젝트, JSON, PNG 스프라이트시트 내보내기
- 투명 always-on-top 데스크톱 펫 실행과 자동 이동·방향 전환·클릭 반응
