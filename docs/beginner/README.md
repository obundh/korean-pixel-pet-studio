## 가장 짧은 성공 경로

이미 픽셀 이미지가 있다면 **빠른 펫 만들기**를 사용하세요.

```text
픽셀 이미지 1장
  → 빠른 펫 만들기
  → 자동 배경 제거
  → 선택한 스타일 크기로 정규화(기본 예시 64×64)
  → 대기 프레임 4장
  → 움직임 확인
  → 프로젝트 저장 및 데스크톱 실행
```

원본 마스코트가 일반 일러스트라면 AI에서 먼저 기준 픽셀 마스터를 만든 뒤, 앱이 제공하는 대기 포즈 가이드 한 장으로 4칸 시트를 만드는 정식 경로를 사용하세요.

## 문서를 읽는 방법

앱 버튼은 **굵은 글씨**로 표시합니다. 파일 이름과 폴더 이름은 `이런 글씨`로 표시합니다. 각 단계의 “정상이라면” 항목이 보이면 다음 단계로 넘어가면 됩니다.

## 꼭 기억할 세 가지

1. 내가 준비할 이미지는 마스코트 원본 한 장입니다.
2. 두 번째 AI 요청에는 픽셀 마스터와 대기 포즈 가이드, 두 장만 첨부합니다.
3. 계속 편집하려면 마지막에 `.pixelpet` 프로젝트를 저장해야 합니다.
