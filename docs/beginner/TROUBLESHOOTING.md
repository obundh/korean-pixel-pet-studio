# 문제해결

먼저 프로젝트를 저장할 수 있다면 위쪽 **저장**을 눌러 현재 상태를 보관하세요. 이후 아래에서 증상과 가장 가까운 항목을 찾습니다.

## 설치와 실행

### Windows에서 “PC를 보호했습니다”가 나옵니다

현재 앱이 Microsoft 코드 서명 인증서로 서명되지 않아 나타날 수 있습니다.

1. 공식 [GitHub Releases](https://github.com/obundh/korean-pixel-pet-studio/releases/latest)에서 받은 파일인지 확인합니다.
2. 출처를 확인한 경우 **추가 정보 → 실행**을 선택합니다.
3. 다른 사이트에서 받은 파일이면 실행하지 않습니다.

SmartScreen이나 백신 전체를 끄지 마세요. 자세한 과정은 [Windows 설치](INSTALL_WINDOWS.md)에 있습니다.

### Mac에서 개발자를 확인할 수 없다고 합니다

1. 공식 Releases에서 받은 앱인지 확인합니다.
2. 응용 프로그램 폴더에서 앱을 Control-클릭합니다.
3. **열기 → 열기**를 선택합니다.

Apple Silicon Mac은 `arm64`, Intel Mac은 `x64` DMG를 받아야 합니다. [macOS 설치](INSTALL_MACOS.md)를 확인하세요.

### 앱이 열리지만 레퍼런스가 비어 있습니다

앱을 완전히 종료한 뒤 다시 실행합니다. 계속 비어 있다면 설치 파일이 완전히 내려받아졌는지 확인하고 공식 릴리스에서 다시 설치하세요. 개발용 소스 ZIP은 완성 앱이 아닙니다.

## 이미지 가져오기

### 파일을 선택해도 들어오지 않습니다

다음을 확인하세요.

- PNG, JPG 또는 WebP인가
- 한 장당 20MB 이하인가
- 전체 4MP(400만 픽셀) 이하이고 가로와 세로가 각각 4096px 이하인가
- 실제 이미지 파일이며 확장자만 바꾼 파일이 아닌가
- 이미지가 다른 프로그램에서 정상적으로 열리는가

필요하면 이미지 편집기에서 PNG로 다시 저장합니다.

### 고급 모드에서 개별 파일 순서가 뒤섞였습니다

파일 이름을 두 자리 번호로 바꿉니다.

```text
idle-01.png
idle-02.png
idle-03.png
idle-04.png
```

잘못 들어간 슬롯은 휴지통으로 비운 뒤 다시 **개별 포즈 여러 장 가져오기**를 사용하세요. 기본 흐름에서는 개별 파일을 쓰지 않습니다. 왼쪽부터 시간순인 가로 시트 한 장을 가져오면 이 문제를 피할 수 있습니다.

### 이미지 크기가 제각각입니다

AI에 포즈를 완전히 같은 크기의 가로 셀 안에 배치해 달라고 요청하세요. 앱에 넣은 뒤 **이 동작 한 번에 정리**를 누르면 넓고 안정적인 몸통 행을 기준으로 작은 좌우 드리프트만 제한적으로 보정하고, 세로 위치는 유지한 채 모든 포즈에 하나의 공통 캔버스와 배율을 적용합니다. 팔이나 꼬리 하나가 길게 뻗었다는 이유만으로 캐릭터 전체를 무제한 이동시키지는 않습니다.

### “포즈 시트 가로를 똑같이 나눌 수 없어요”가 나옵니다

선택한 동작의 슬롯 수와 시트 칸 수가 맞지 않는 경우입니다.

- 대기·잠자기: 4칸
- 걷기: 8칸
- 점프·반응: 6칸

시트는 한 줄이어야 하고 전체 가로 픽셀 수가 칸 수로 정확히 나누어져야 합니다. 예를 들어 대기 시트는 3840×960처럼 가로를 4로 나눌 수 있어야 합니다. 2×2 콜라주, 칸마다 다른 너비, 바깥 여백이 비대칭인 결과는 AI에서 다시 만드는 편이 안전합니다.

### 포즈 시트를 가져왔는데 순서가 반대입니다

앱은 시트를 **왼쪽에서 오른쪽**으로 읽습니다. 앱 안에서 자동으로 의미를 판단해 순서를 바꾸지 않습니다. AI에 `F01 → F02 → F03 → F04`를 왼쪽부터 배치하라고 요청한 뒤 다시 가져오세요.

### 시트의 구분선이나 번호도 프레임에 들어왔습니다

앱은 같은 너비로 자르기만 하므로 선, 번호와 글자를 자동으로 지우지 않습니다. AI에 다음 문구로 수정 요청하세요.

```text
네 포즈와 단색 배경은 유지하고 칸 사이 선, 프레임 번호, 글자와 바깥 테두리만 제거하라.
완전히 같은 너비의 4칸을 한 줄로 배치하라.
```

## 빠른 펫 만들기

### “이미지 한 장 고르기” 버튼이 비활성화되어 있습니다

처리 중인 작업이 끝날 때까지 기다립니다. 지원 이미지 형식과 20MB·4MP·한 변 4096px 제한도 확인하세요. 여전히 사용할 수 없다면 앱을 다시 시작하고 이미지 한 장만 선택합니다.

### 대기 프레임이 4장 만들어지지 않았습니다

1. 프로젝트를 저장할 수 있다면 먼저 저장합니다.
2. 대기 탭의 기존 슬롯을 확인합니다.
3. 빠른 만들기를 다시 실행합니다.
4. 반복 실패하면 원본을 PNG로 다시 저장해 시도합니다.

빠른 만들기는 다른 동작 슬롯을 자동으로 채우지 않습니다. 걷기, 점프, 잠자기와 반응은 별도의 실제 포즈 시트를 만들어야 합니다.

### 빠른 모드인데 팔이나 꼬리가 움직이지 않습니다

정상입니다. 빠른 모드는 이미지 한 장을 `0px → 위로 1px → 위로 1px → 0px`로만 이동하는 4 FPS 무왜곡 bob입니다. 몸 전체를 늘이거나 찌그러뜨리지는 않지만 새 포즈를 만들지도 않습니다.

팔, 꼬리, 귀, 눈과 장식이 실제로 움직이게 하려면 [AI 생성 가이드](CREATE_WITH_AI.md)의 4칸 가로 포즈 시트를 만든 뒤 **포즈 시트 한 장 가져오기 → 이 동작 한 번에 정리**를 사용하세요.

### 정규화 결과에서 캐릭터가 너무 작습니다

입력 이미지의 빈 여백을 줄인 뒤 다시 시도하세요. 캐릭터 전신을 자르지는 말고, 주변 배경 여백만 줄입니다.

## 배경 제거

### “이 동작 한 번에 정리”가 실패합니다

1. 현재 동작 슬롯에 프레임이 하나 이상 들어 있는지 확인합니다.
2. 모든 칸에 캐릭터 전신이 보이는지 확인합니다.
3. 체커보드 그림 대신 한 가지 단색 배경을 사용합니다.
4. 캐릭터와 배경색이 겹치지 않는지 확인합니다.
5. 문제가 있는 시트를 PNG로 다시 저장해 가져옵니다.

일괄 정리는 단색 배경, 이미 투명한 PNG와 일반 배경을 구분해 처리합니다. 첫 일반 배경 처리에서는 로컬 AI 모델을 여는 시간이 더 걸릴 수 있습니다.

### 첫 배경 제거가 오래 걸립니다

첫 처리에서는 앱에 포함된 AI 모델을 메모리에 올립니다. 진행률이 변하고 있다면 기다리세요. 같은 버튼을 반복해서 누르거나 앱을 강제 종료하지 않는 것이 좋습니다.

### 배경이 일부 남습니다

원본이 다음 조건을 만족하는지 확인합니다.

- 캐릭터와 배경의 색 차이가 큼
- 배경이 단색에 가까움
- 바닥 그림자나 복잡한 장면이 없음
- 전신이 잘리지 않음

AI에서 캐릭터에 없는 단색 배경으로 다시 생성한 뒤 프레임을 **교체**하고 배경 제거를 실행하세요.

### 귀, 꼬리, 손발도 같이 지워집니다

캐릭터와 배경의 색이 비슷하면 생길 수 있습니다. **원본 복원**을 누른 뒤 대비가 큰 배경의 이미지로 교체하세요. 가느다란 장식은 픽셀 마스터 단계에서 조금 더 굵고 읽기 쉽게 보존하도록 요청하는 것도 도움이 됩니다.

### 흰색·초록색 테두리가 남습니다

생성 이미지에 안티앨리어싱 또는 배경색이 섞인 반투명 가장자리가 들어간 경우입니다.

1. AI에 안티앨리어싱과 반투명 테두리를 금지해 다시 생성합니다.
2. 캐릭터와 겹치지 않는 단색 배경을 사용합니다.
3. 새 파일로 교체한 뒤 배경 제거를 다시 실행합니다.

### 투명한 줄 알았는데 체커보드가 남습니다

AI가 투명 표시처럼 보이는 회색 체크무늬를 실제 배경으로 그린 것입니다. PixelPet Studio에서 배경 제거를 실행하거나, AI에 “체커보드를 그리지 말고 완전한 단색 배경”으로 다시 요청하세요.

## AI 생성 결과

### 이미지가 10장쯤 필요한가요?

아닙니다. 사용자가 준비할 이미지는 마스코트 한 장입니다.

- 첫 번째 AI 요청: 원본 1장
- 두 번째 AI 요청: 픽셀 마스터 1장 + 앱의 대기 포즈 가이드 1장
- 앱에 가져오기: 완성된 4칸 시트 1장

**대기 포즈 가이드 1장에는 4컷이 한 파일에 들어 있습니다.** 별도 스타일 이미지와 포즈 낱장은 필요하지 않습니다.

### AI가 2×2 콜라주를 만들었습니다

다음 문장을 추가해 다시 요청합니다.

```text
2×2 콜라주가 아니다.
네 포즈를 완전히 같은 너비와 높이의 셀에 넣어 왼쪽부터 오른쪽으로 배치한 한 줄짜리 가로 시트로 출력하라.
칸 사이 선, 번호, 글자와 간격 띠는 넣지 마라.
```

### 프레임마다 다른 캐릭터처럼 보입니다

- 원본보다 승인한 기준 픽셀 마스터를 `REFERENCE 1`로 사용
- 앱에서 저장한 대기 포즈 가이드 한 장을 `REFERENCE 2`로 사용
- 원본, 별도 스타일 이미지와 포즈 낱장을 다시 첨부하지 않음
- 바뀌면 안 되는 얼굴, 색, 로고, 의상과 장식을 시트 프롬프트에 명시
- 네 칸 모두 같은 카메라, 크기, 몸 중심과 발 기준선을 요구
- 틀린 부분만 최소 수정 요청

자세한 절차는 [AI로 이미지 만들기](CREATE_WITH_AI.md)를 확인하세요.

### 팔다리나 꼬리가 늘어났습니다

틀린 결과와 기준 픽셀 마스터를 함께 첨부하고 다음처럼 구체적으로 요청합니다.

```text
현재 결과를 새로 그리지 말고 꼬리 2개를 기준 이미지와 같은 1개로만 수정하라.
얼굴, 색, 포즈와 다른 픽셀은 유지하라.
```

## 미리보기와 데스크톱 펫

### 움직임이 위아래로 떨립니다

먼저 **프레임 가져오기**로 돌아가 **이 동작 한 번에 정리**를 실행했는지 확인합니다. 이 기능은 프레임마다 따로 자르거나 확대하지 않고 모든 포즈에 같은 공통 좌표와 배율을 적용합니다.

그래도 떨리면 재생을 멈추고 아래 프레임 점을 하나씩 눌러 확인하세요. 앱은 시트에 그려진 발 위치를 임의로 바꾸지 않습니다. AI가 특정 칸에서 캐릭터 자체를 위로 그렸거나 다리 길이를 바꾼 경우에는 정렬만으로 고칠 수 없으므로 그 칸의 포즈를 시트에서 수정한 뒤 다시 가져와야 합니다.

### 캐릭터가 프레임마다 늘어나거나 납작해집니다

앱의 일괄 정리는 모든 포즈에 같은 배율을 적용하므로 프레임별 전체 스쿼시를 만들지 않습니다. 입력 시트에서 이미 몸 전체 크기가 달라진 경우입니다.

AI에 다음처럼 수정 요청하세요.

```text
캐릭터 전체의 가로세로 비율, 머리·몸 크기와 발 기준선은 네 칸 모두 동일하게 유지하라.
전체 이미지를 확대, 축소, 늘이기 또는 납작하게 만들지 말고 팔, 꼬리, 귀, 눈과 장식의 필요한 픽셀만 움직여라.
```

### 캐릭터가 흐릿합니다

원본이 픽셀아트가 아니거나 서로 다른 크기의 가짜 픽셀이 포함됐을 수 있습니다. 빠른 만들기의 선택 스타일 캔버스 정규화를 사용하거나, AI에 하드 픽셀과 안티앨리어싱 금지를 요청하세요. 화면 배율은 가능한 정수값 2×, 3×, 4×를 우선 사용합니다.

### 특정 동작이 재생되지 않습니다

기본 화면에서는 대기만 재생합니다. 걷기·점프·잠자기·반응을 직접 추가했다면 **선택 동작 미리보기**를 펼치고, 해당 동작에 실제 프레임이 있는지 확인하세요. 비어 있는 선택 동작은 재생할 수 없지만 첫 펫 완성에는 필요하지 않습니다.

일괄 정리 후 기본 속도는 대기·잠자기 4 FPS, 걷기·점프·반응 8 FPS이며 각 동작에 따로 저장됩니다. 프레임이 한 장뿐이면 실제 프레임 전환이 보이지 않습니다.

### 데스크톱에서 펫이 보이지 않습니다

1. 최소 한 동작에 프레임이 있는지 확인합니다.
2. 현재 동작에 프레임이 있는지 확인합니다.
3. **데스크톱 펫 종료** 후 다시 실행합니다.
4. 앱을 종료했다가 프로젝트를 다시 불러옵니다.

여러 모니터를 사용한다면 기본 모니터 화면 가장자리도 확인하세요.

## 저장과 불러오기

### `.pixelpet`과 JSON 중 무엇을 저장해야 하나요?

계속 편집하려면 `.pixelpet`을 저장하세요. JSON은 개발 도구와 연결하는 고급 내보내기입니다. PNG 스프라이트시트도 편집 상태를 복원하지 못합니다.

### 저장한 프로젝트가 너무 큽니다

`.pixelpet`에는 가져온 원본과 투명 결과가 들어갑니다. 큰 AI 원본을 많이 넣으면 파일이 커집니다.

- 필요 이상의 고해상도 이미지를 줄임
- 사용하지 않는 슬롯 삭제
- 동작별로 프로젝트를 나누어 백업
- 최종본에서는 필요한 프레임만 유지

프로젝트 파일은 최대 128MiB 제한이 있습니다.

### 프로젝트를 불러오지 못합니다

- 파일 확장자가 `.pixelpet` 또는 앱에서 내보낸 JSON인지 확인
- 파일을 메모장이나 다른 프로그램에서 수정하지 않았는지 확인
- 다른 앱의 JSON을 PixelPet 프로젝트로 열고 있지 않은지 확인
- 원본 파일의 복사본이 있다면 복사본으로 시도

## 해결되지 않으면

문제를 보고할 때 다음 정보를 함께 준비하면 원인을 찾기 쉽습니다.

- Windows 또는 macOS 버전
- 받은 설치 파일 이름의 `x64` 또는 `arm64`
- 어느 단계와 어느 버튼에서 발생했는지
- 화면에 나온 오류 문장
- 문제가 있는 원본 파일의 형식과 크기. 권리나 개인정보 문제가 있으면 이미지는 첨부하지 않아도 됨
- 재현 순서

공개해도 되는 내용만 포함해 [GitHub Issues](https://github.com/obundh/korean-pixel-pet-studio/issues)에 보고하세요.
