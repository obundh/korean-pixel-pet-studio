# 픽셀 펫 완성 체크리스트

처음에는 아래 세 줄만 기억하세요.

> - **내가 준비할 이미지: 1장**
> - **AI 첨부: 첫 요청 1장, 두 번째 요청 2장**
> - **앱에 넣을 파일: 4칸 시트 1장**

## 시작 전

- [ ] Windows/macOS에 맞는 공식 설치 파일을 받았다.
- [ ] 마스코트 이미지 한 장을 골랐다.
- [ ] 마스코트를 사용하고 변형할 권한을 확인했다.
- [ ] 기관 로고와 브랜드 가이드의 공개 범위를 확인했다.
- [ ] 원본에 캐릭터 전신이 선명하게 보인다.

## 첫 번째 AI 요청

- [ ] 원본 마스코트 **한 장만** 첨부했다.
- [ ] 별도 스타일 이미지나 포즈 이미지를 첨부하지 않았다.
- [ ] 앱의 **1차 프롬프트 복사**를 사용했다.
- [ ] 얼굴, 색, 로고, 의상과 장식을 글로 적었다.
- [ ] 결과에 캐릭터가 한 명만 있다.
- [ ] 전신이 잘리지 않았다.
- [ ] 원본을 아는 사람이 같은 캐릭터라고 알아볼 수 있다.
- [ ] 결과를 `canonical-master.png`로 저장했다.

## 두 번째 AI 요청

- [ ] 앱에서 **대기 포즈 가이드 1장 저장**을 눌렀다.
- [ ] 포즈 가이드의 4컷이 한 파일에 들어 있는지 확인했다.
- [ ] 픽셀 마스터 1장과 대기 포즈 가이드 1장만 첨부했다.
- [ ] 원본, 별도 스타일 이미지, 포즈 낱장 4개를 다시 첨부하지 않았다.
- [ ] 앱의 **2차 프롬프트 복사**를 사용했다.
- [ ] 결과가 2×2가 아닌 가로 한 줄의 4칸이다.
- [ ] 네 칸의 너비와 높이가 같다.
- [ ] 칸 사이 선, 번호, 글자와 간격 띠가 없다.
- [ ] 캐릭터 크기와 발 기준선이 비슷하다.
- [ ] 얼굴, 색, 로고와 장식이 유지된다.
- [ ] 마지막 포즈에서 첫 포즈로 자연스럽게 이어진다.
- [ ] 결과를 `idle-sheet.png`로 저장했다.

## 앱에서 시트 한 장 처리하기

- [ ] 기본 화면의 **대기 포즈 시트 한 장 가져오기**로 `idle-sheet.png` 한 장을 선택했다.
- [ ] “대기 시트를 4컷으로 나눴어요”와 `4/4컷`이 보인다.
- [ ] **움직임 확인**에서 왼쪽부터 재생되는 순서가 올바르다.
- [ ] **이 동작 한 번에 정리**를 눌렀다.
- [ ] **공통 좌표 정리 완료**가 보인다.
- [ ] 네 프레임의 바깥 배경이 투명하다.
- [ ] 귀, 꼬리, 손발과 장식이 지워지지 않았다.
- [ ] 흰색이나 초록색 테두리가 남지 않았다.

## 움직임 확인

- [ ] 대기 동작이 4 FPS로 재생된다.
- [ ] 프레임 순서가 자연스럽다.
- [ ] 마지막에서 첫 프레임으로 돌아갈 때 튀지 않는다.
- [ ] 얼굴과 몸 크기가 갑자기 변하지 않는다.
- [ ] 발 기준선이 크게 흔들리지 않는다.
- [ ] 팔, 꼬리, 귀, 눈 또는 장식이 실제로 움직인다.
- [ ] 몸 전체가 늘어나거나 납작해지지 않는다.

## 저장과 실행

- [ ] `.pixelpet` 프로젝트를 찾기 쉬운 폴더에 저장했다.
- [ ] **데스크톱에서 실행**했을 때 펫이 보인다.
- [ ] **데스크톱 펫 종료**가 동작한다.
- [ ] 저장한 프로젝트를 **불러오기**로 다시 열어 보았다.

## 공개 또는 전달 전

- [ ] 권리자가 공개·배포를 허락했다.
- [ ] 생성 AI 서비스의 이용조건을 확인했다.
- [ ] 외부 이미지의 출처와 확인 날짜를 기록했다.
- [ ] 외부 마스코트에 프로젝트의 AGPL 코드 라이선스나 CC BY 자산 라이선스를 적용하지 않았다.
- [ ] 개인 정보나 내부 기관 자료가 프로젝트 파일에 없다.
- [ ] 코드 서명되지 않은 실행 파일이라는 점을 전달받는 사람에게 알렸다.

## 선택사항

첫 대기 펫을 완성한 뒤에만 확인하세요.

- [ ] 이미지 한 장 빠른 모드 시험
- [ ] 걷기, 점프, 잠자기 또는 반응 동작 추가
- [ ] 측면·뒷면 원본 추가
- [ ] 별도 스타일 레퍼런스 사용
- [ ] 개별 포즈 파일로 정밀 수정
- [ ] 스프라이트시트 PNG 또는 JSON 내보내기

이 항목은 기본 완성 조건이 아닙니다.
