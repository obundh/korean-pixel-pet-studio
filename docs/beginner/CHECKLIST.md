# 픽셀 펫 완성 체크리스트

필요하면 이 페이지를 인쇄하거나 복사해 체크하세요. 처음에는 **대기 프레임 4장**과 **프로젝트 저장**까지만 완료해도 충분합니다.

## 시작 전

- [ ] Windows/macOS에 맞는 공식 설치 파일을 받았다.
- [ ] 마스코트를 사용하고 변형할 권한을 확인했다.
- [ ] 기관 로고와 브랜드 가이드의 공개 범위를 확인했다.
- [ ] 원본, 생성 이미지, 프로젝트를 보관할 폴더를 만들었다.
- [ ] 원본 이미지에 캐릭터 전신이 선명하게 보인다.

## AI로 기준 이미지 만들기

- [ ] 원본 마스코트를 `REFERENCE 1`로 첨부했다.
- [ ] 스타일 레퍼런스를 `REFERENCE 2`로 첨부했다.
- [ ] 바뀌면 안 되는 얼굴, 색, 로고, 의상, 장식을 글로 적었다.
- [ ] 기준 픽셀 마스터에 캐릭터가 한 명만 있다.
- [ ] 전신과 부속물이 캔버스 안에 있다.
- [ ] 원본을 아는 사람이 같은 캐릭터라고 알아볼 수 있다.
- [ ] 승인한 기준 이미지를 별도 파일로 저장했다.

## 포즈 프레임 만들기

- [ ] 승인한 기준 픽셀 마스터를 가장 먼저 첨부했다.
- [ ] 기준 마스터 때 사용한 같은 스타일을 첨부했다.
- [ ] 현재 순번의 포즈 레퍼런스 한 장만 첨부했다.
- [ ] 한 요청에 결과 한 장만 생성했다.
- [ ] 파일명을 `idle-01`처럼 두 자리 순번으로 저장했다.
- [ ] 모든 프레임의 캐릭터 크기와 발 기준선이 비슷하다.
- [ ] 프레임마다 얼굴, 색, 로고, 장식이 유지된다.

## 빠른 펫 만들기

- [ ] 입력 이미지가 픽셀 캐릭터 한 명을 담고 있다.
- [ ] **이미지 한 장으로 자동 완성** 카드에서 **이미지 한 장 고르기**를 실행했다.
- [ ] 대기 탭이 `4/4`로 채워졌다.
- [ ] 캐릭터가 선택한 스타일 캔버스 안에서 잘리지 않았다.
- [ ] 캐릭터 바깥 배경이 투명하다.

## 앱에 프레임 넣기

- [ ] 올바른 동작 탭을 선택했다.
- [ ] 슬롯 01부터 파일 순서가 맞다.
- [ ] 다른 동작의 이미지가 섞이지 않았다.
- [ ] 사용할 모든 프레임이 슬롯에 보인다.
- [ ] 각 이미지는 PNG, JPG 또는 WebP이고 20MB·전체 4MP 이하이며 가로와 세로가 각각 4096px 이하이다.

## 배경 제거

- [ ] 사용할 모든 프레임에 배경 제거 완료 표시가 있다.
- [ ] 캐릭터의 귀, 꼬리, 손발이나 장식이 지워지지 않았다.
- [ ] 흰색, 초록색 또는 검은색 테두리가 남지 않았다.
- [ ] 바닥선, 그림자, 글자, 워터마크가 남지 않았다.
- [ ] 문제가 있는 프레임은 원본 복원 또는 교체했다.

## 움직임 확인

- [ ] 프레임 순서가 자연스럽다.
- [ ] 얼굴과 몸 크기가 갑자기 변하지 않는다.
- [ ] 발 기준선이 크게 흔들리지 않는다.
- [ ] 재생 속도가 너무 빠르거나 느리지 않다.
- [ ] 화면 배율에서 픽셀이 흐릿하지 않다.

## 저장과 실행

- [ ] 프로젝트 이름을 알아보기 쉽게 정했다.
- [ ] `.pixelpet` 프로젝트를 찾기 쉬운 폴더에 저장했다.
- [ ] **데스크톱에서 실행**했을 때 펫이 보인다.
- [ ] 앱에서 **데스크톱 펫 종료**가 동작한다.
- [ ] 저장한 프로젝트를 **불러오기**로 다시 열어 보았다.
- [ ] 필요하다면 스프라이트시트 PNG도 내보냈다.

## 공개 또는 전달 전

- [ ] 원본 마스코트 권리자가 공개·배포를 허락했다.
- [ ] 생성 AI 서비스의 이용조건을 확인했다.
- [ ] 외부 이미지의 출처와 확인 날짜를 기록했다.
- [ ] 외부 마스코트에 프로젝트의 MIT 라이선스를 잘못 적용하지 않았다.
- [ ] 개인 정보나 내부 기관 자료가 프로젝트 파일에 포함되지 않았다.
- [ ] 코드 서명되지 않은 실행 파일이라는 점을 전달받는 사람에게 알렸다.
