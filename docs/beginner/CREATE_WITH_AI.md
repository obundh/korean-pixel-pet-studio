# GPT·Gemini로 실제 포즈 시트 만들기

이 문서는 일반 마스코트 일러스트를 PixelPet Studio용 픽셀 애니메이션으로 만드는 가장 쉬운 흐름을 설명합니다.

```text
원본 마스코트 + 스타일 레퍼런스
  → 기준 픽셀 마스터 한 장 승인

기준 픽셀 마스터 + 같은 스타일 + 대기 포즈 F01~F04
  → 왼쪽부터 시간순인 4칸 가로 포즈 시트 한 장

PixelPet Studio
  → 시트 4등분
  → 이 동작 한 번에 정리
  → 4 FPS 실제 프레임 재생
```

GPT와 Gemini의 버튼 위치는 바뀔 수 있습니다. 화면 모양보다 **첨부 이미지의 역할**, **같은 캐릭터 유지**, **한 줄의 같은 너비 칸**, **왼쪽→오른쪽 순서**를 기억하세요.

## 빠른 모드와 실제 포즈의 차이

PixelPet Studio의 **이미지 한 장으로 자동 완성**은 한 그림을 `0px → 위로 1px → 위로 1px → 0px`로 옮기는 4 FPS 무왜곡 bob입니다. 몸을 늘이거나 찌그러뜨리지 않으므로 앱 실행을 빨리 시험하기에는 안전하지만, 팔·다리·표정·꼬리가 변하는 진짜 포즈 애니메이션은 아닙니다.

공식 샘플처럼 실제 움직임을 만들려면 AI가 서로 다른 포즈를 그린 가로 시트가 필요합니다.

## 역할 분담

| 단계 | 담당 |
|---|---|
| 마스코트를 픽셀아트로 다시 그리기 | GPT, Gemini 등 이미지 생성 AI |
| 같은 캐릭터의 서로 다른 실제 포즈 만들기 | 이미지 생성 AI |
| 가로 시트를 정확히 같은 너비로 나누기 | PixelPet Studio |
| 단색·일반 배경 투명화 | PixelPet Studio의 로컬 처리 |
| 넓고 안정적인 몸통 행을 기준으로 작은 좌우 드리프트만 제한적으로 보정하고, 세로 위치를 유지하며 모든 포즈에 공통 캔버스·배율 적용 | PixelPet Studio |
| 실제 프레임 재생, 저장, 데스크톱 실행 | PixelPet Studio |

PixelPet Studio는 대화형 이미지 생성 서비스를 내장하지 않습니다. 외부 AI에 올린 원본에는 해당 서비스의 이용약관과 데이터 정책이 적용됩니다. 기관 마스코트, 로고와 브랜드 이미지는 변형·AI 입력·공개·재배포 권한을 각각 확인해야 합니다.

## 1. 원본 마스코트 점검

다음 조건에 가까운 이미지를 준비하세요.

- 전신이 잘리지 않고 선명함
- 얼굴, 대표 색, 의상, 로고, 장식이 가려지지 않음
- 캐릭터가 한 명만 있음
- 기관이나 권리자로부터 사용할 권한을 확인함
- 가능하면 정면 이미지와 측면 이미지를 각각 준비함

정면 한 장만 있어도 시작할 수 있습니다. 여러 캐릭터가 함께 있는 단체 이미지는 피하세요.

## 2. 바뀌면 안 되는 특징 적기

AI에 보내기 전에 아래 네 줄을 직접 채우세요.

```text
캐릭터 한 줄 설명: [예: 둥근 파란 몸과 노란 별 안테나가 있는 작은 우주 생물]
반드시 유지할 색: [예: 몸 파랑, 안테나 별 노랑, 눈 진한 남색]
반드시 유지할 형태: [예: 안테나 1개, 팔 2개, 짧은 다리 2개]
반드시 유지할 표식·의상: [예: 가슴의 흰색 원형 표식]
```

HEX 색상 코드를 몰라도 됩니다. “밝은 민트색 몸”, “자주색 목도리”처럼 눈으로 구분되는 표현이면 충분합니다.

## 3. 스타일과 포즈 레퍼런스 저장

1. PixelPet Studio에서 **생성 가이드**를 엽니다.
2. **스타일 선택**에서 원하는 스타일 하나를 누릅니다.
3. **선택한 스타일 레퍼런스 저장**을 누릅니다.
4. **대기**를 선택합니다.
5. F01, F02, F03, F04 포즈 이미지를 각각 저장합니다.

처음이라면 64×64 스타일을 권장합니다. 한 펫의 모든 프레임에서 같은 스타일과 캔버스 크기를 사용하세요.

스타일 레퍼런스는 픽셀 크기, 외곽선과 명암 방식만 전달합니다. 그 안의 캐릭터 형태나 색을 복사하면 안 됩니다. 포즈 레퍼런스도 회색 도형을 복사하는 자료가 아니라 관절, 무게 중심과 시간 순서를 알려 주는 자료입니다.

## 4. 기준 픽셀 마스터 만들기

### 첨부 순서

1. `REFERENCE 1`: 내 원본 마스코트
2. `REFERENCE 2`: 앱에서 저장한 스타일 레퍼런스

### 복사해서 쓰는 프롬프트

대괄호 부분을 내 캐릭터에 맞게 바꾸세요.

```text
REFERENCE 1은 정체성을 바꾸면 안 되는 원본 마스코트다.
REFERENCE 2는 픽셀 크기, 외곽선, 색 덩어리와 명암 방식만 참고하는 스타일 자료다.
REFERENCE 2의 캐릭터 형태와 색은 복사하지 않는다.

REFERENCE 1의 동일한 캐릭터를 작은 데스크톱 펫용 픽셀아트로 다시 그려라.

캐릭터 한 줄 설명: [여기에 작성]
반드시 유지할 색: [여기에 작성]
반드시 유지할 형태: [여기에 작성]
반드시 유지할 표식·의상: [여기에 작성]

조건:
- 캐릭터 전신 하나만 중앙에 배치
- 앱에서 선택한 [64×64 또는 96×96] 결과에 맞는 또렷한 하드 픽셀
- 같은 크기의 픽셀, 제한된 팔레트, 일정한 외곽선
- 얼굴, 대표 색, 로고, 의상과 고유 장식을 원본과 같게 유지
- 글자, 번호, 워터마크, 소품, 바닥선과 외부 그림자 금지
- 안티앨리어싱, 블러와 사진 같은 질감 금지
- 배경은 캐릭터에 전혀 쓰이지 않은 완전한 단색 한 가지
- 설명이나 비교판 없이 이미지 한 장만 출력

새 캐릭터를 창작하거나 특정 게임·작가·프랜차이즈의 화풍을 모사하지 마라.
```

### 승인 확인

- 원본을 아는 사람이 같은 캐릭터라고 알아볼 수 있는가?
- 얼굴, 대표 색, 로고, 의상과 장식의 개수·위치가 맞는가?
- 귀, 꼬리, 팔과 다리가 임의로 늘거나 사라지지 않았는가?
- 전신이 잘리지 않았는가?
- 픽셀 크기와 외곽선이 일정한가?

모두 맞으면 `canonical-master.png`처럼 이름 붙여 따로 보관합니다.

## 5. 대기 4칸 가로 포즈 시트 만들기

### 첨부 순서

1. `REFERENCE 1`: 승인한 기준 픽셀 마스터
2. `REFERENCE 2`: 기준 마스터 때 사용한 같은 스타일 레퍼런스
3. `REFERENCE 3~6`: 대기 F01, F02, F03, F04 포즈 레퍼런스
4. 원본 마스코트: 기준 마스터에서 가려진 특징을 확인해야 할 때만 추가

### 복사해서 쓰는 4칸 시트 프롬프트

```text
REFERENCE 1의 승인된 픽셀 캐릭터 정체성과 픽셀 스타일을 그대로 유지하라.
REFERENCE 2는 픽셀 크기, 외곽선과 명암 규칙만 확인하는 자료다.
REFERENCE 3, 4, 5, 6은 각각 시간순 F01, F02, F03, F04의 관절과 무게 중심만 참고한다.
포즈 자료의 회색 도형, 색, 비율과 관절점은 결과에 복사하지 않는다.

같은 캐릭터의 실제 대기 애니메이션 포즈 4개를 한 장에 만들어라.

출력 배치:
- 가로로 긴 한 줄
- 완전히 같은 너비와 높이의 4칸
- 왼쪽부터 F01, F02, F03, F04 시간순
- 칸 사이 선, 테두리, 간격 띠, 글자와 프레임 번호 없음
- 각 칸에 캐릭터 한 명씩, 같은 카메라·크기·몸 중심·발 기준선

움직임:
- F01: 중립 대기
- F02: 가슴, 손, 귀 또는 장식이 조금 올라가는 들숨
- F03: 중립으로 돌아오는 연결 포즈
- F04: 눈꺼풀, 꼬리 끝 또는 장식이 조금 내려가는 날숨
- 팔, 꼬리, 귀, 눈과 장식 등 필요한 부분의 픽셀을 실제로 바꿀 것
- 캐릭터 전체를 기하학적으로 확대, 축소, 늘이기 또는 납작하게 만들지 말 것
- F04에서 F01로 자연스럽게 이어지는 반복 동작

고정 조건:
- REFERENCE 1의 얼굴, 실루엣, 대표 색, 의상, 로고와 장식 유지
- 네 칸 모두 같은 픽셀 크기, 외곽선 굵기와 빛 방향
- 전신과 부속물이 각 칸 안에 들어감
- 바닥 그림자, 효과선, 소품, 추가 캐릭터와 워터마크 없음
- 배경은 네 칸 전체에 걸쳐 캐릭터에 없는 완전한 단색 한 가지
- 안티앨리어싱, 블러와 반투명 테두리 없음

설명 없이 가로 4칸 이미지 한 장만 출력하라.
```

### 저장 전 확인

- 한 줄에 정확히 네 포즈가 있는가?
- 각 칸의 너비가 같은가?
- 왼쪽부터 `F01 → F02 → F03 → F04`인가?
- 칸 사이 구분선이나 글자가 없는가?
- 발 기준선과 캐릭터 크기가 비슷한가?
- 얼굴, 색, 장식이 네 칸 모두 같은가?
- 몸 전체가 찌그러진 복사본이 아니라 실제 부분 포즈가 다른가?

결과를 `idle-sheet.png`로 저장합니다.

## 6. PixelPet Studio에서 시트 처리

1. **프레임 가져오기**를 엽니다.
2. **대기** 탭을 선택합니다.
3. **포즈 시트 한 장 가져오기**를 누릅니다.
4. `idle-sheet.png`를 선택합니다.
5. 앱이 왼쪽부터 4등분해 01~04 슬롯을 채웠는지 확인합니다.
6. **이 동작 한 번에 정리**를 누릅니다.
7. “공통 좌표 정리 완료”가 나올 때까지 기다립니다.
8. **움직임 확인**에서 4 FPS로 재생합니다.

앱은 포즈를 새로 만들지 않습니다. 시트를 나누고 배경을 투명하게 만든 뒤, 머리·몸통처럼 넓고 안정적인 가로 행의 중앙값으로 AI가 만든 작은 좌우 드리프트를 찾습니다. 팔·꼬리·안테나처럼 얇게 뻗은 부분은 중심 계산의 영향이 작고, 보정 폭에도 상한이 있어 실제 비대칭 포즈 때문에 캐릭터 전체가 멀리 밀리지 않습니다. 그 다음 네 포즈 전체를 하나의 공통 캔버스와 배율로 정렬합니다. 세로 위치나 서로 다른 발 높이는 자동으로 같은 곳으로 옮기지 않으므로 시트 생성 단계에서 발 기준선을 맞춰야 합니다.

### 시트 파일 제한

- PNG, JPG 또는 WebP
- 전체 파일 20MB 이하
- 전체 4MP(400만 픽셀) 이하
- 가로와 세로 각각 4096px 이하
- 가로 길이가 선택한 슬롯 수로 정확히 나누어져야 함

대기 4칸 시트가 너무 크다면 각 칸을 960×960 이하로 줄여 전체를 3840×960 이하로 만드는 방법이 쉽습니다. 픽셀아트는 크기를 바꿀 때 nearest-neighbor 보간을 사용하세요.

## 7. GPT·Gemini에서 실패 결과 고치기

새 디자인을 다시 요청하기보다 틀린 부분만 적으세요.

```text
현재 결과를 새로 디자인하지 말고 다음 항목만 최소 수정해라:
- 네 칸을 완전히 같은 너비로 맞추기
- F02의 목수건 끝만 1~2픽셀 위로 움직이기
- F04의 꼬리를 원본과 같은 하나로 복원하기

그 외 얼굴, 색, 픽셀 크기, 외곽선, 배경색과 칸 순서는 유지한다.
설명 없이 가로 4칸 이미지 한 장만 출력한다.
```

AI가 2×2 콜라주를 만들었다면 다음처럼 요청합니다.

```text
2×2 격자나 콜라주가 아니다.
네 포즈를 완전히 같은 크기의 셀에 왼쪽부터 오른쪽으로 배치한 한 줄짜리 가로 시트로 다시 출력하라.
칸 사이 선, 번호와 글자는 넣지 마라.
```

## 8. AI 결과가 투명하지 않아도 괜찮습니다

생성 AI가 투명 배경 대신 흰색이나 초록색 배경을 남겨도 됩니다. 다음 조건이면 앱이 처리하기 쉽습니다.

- 캐릭터에 쓰이지 않은 한 가지 단색 배경
- 네 칸 모두 정확히 같은 배경색
- 복잡한 장면이나 바닥 그림자 없음
- 전신과 부속물이 각 칸 안에 있음
- 캐릭터 가장자리와 배경의 색 차이가 큼

회색 체커보드를 투명 표시처럼 그리게 하지 마세요. 체커보드가 실제 픽셀이면 배경 제거가 어려워집니다.

## 9. 다른 동작 추가

대기 4칸 시트로 성공한 다음 확장하세요.

| 동작 | 가로 시트 칸 수 | 정리 후 기본 FPS |
|---|---:|---:|
| 대기 | 4 | 4 FPS |
| 걷기 | 8 | 8 FPS |
| 점프 | 6 | 8 FPS |
| 잠자기 | 4 | 4 FPS |
| 반응 | 6 | 8 FPS |

동작이 달라도 기준 픽셀 마스터와 스타일 레퍼런스는 바꾸지 않습니다. 시트는 항상 한 줄이고 각 칸의 너비가 같아야 합니다.

이미 프레임별 파일을 따로 만들었다면 **개별 포즈 여러 장 가져오기**도 사용할 수 있습니다. 가져온 뒤에는 같은 **이 동작 한 번에 정리** 버튼으로 전체 좌표를 맞추세요.

더 정밀한 변수와 전체 프롬프트 체계가 필요하면 [고급 프롬프트 가이드](../prompting/README.md)를 참고하세요.
