# GPT·Gemini로 픽셀 이미지 만들기

이 문서는 일반 마스코트 일러스트를 PixelPet Studio에 넣을 픽셀 프레임으로 만드는 방법입니다. GPT와 Gemini의 화면 구성은 바뀔 수 있으므로 버튼 위치보다 **첨부 이미지 순서**와 **한 번에 한 장** 원칙을 기억하세요.

이미 픽셀 이미지 한 장이 있다면 AI 생성 단계를 건너뛰고 [빠른 펫 만들기](APP_WALKTHROUGH.md#가장-쉬운-방법-이미지-한-장으로-자동-완성)를 사용해도 됩니다.

## 먼저 알아둘 역할 분담

| 단계 | 담당 |
|---|---|
| 마스코트를 픽셀아트로 다시 그리기 | GPT, Gemini 등 이미지 생성 AI |
| 같은 캐릭터의 다른 포즈 만들기 | 이미지 생성 AI |
| 이미지 파일 순서 맞추기 | PixelPet Studio |
| 배경 투명화 | PixelPet Studio의 로컬 배경 제거 |
| 선택 스타일 캔버스 정규화와 빠른 대기 루프 | PixelPet Studio의 빠른 만들기 |
| 미리보기, 저장, 데스크톱 실행 | PixelPet Studio |

PixelPet Studio는 현재 대화형 이미지 생성 서비스를 내장하지 않습니다. AI에 올린 원본에는 해당 서비스의 이용약관과 데이터 정책이 적용됩니다. 공개 전 이미지 사용 권한도 직접 확인해야 합니다.

## 전체 과정

```text
원본 마스코트 + 스타일 레퍼런스
  → 기준 픽셀 마스터 1장 승인

기준 픽셀 마스터 + 같은 스타일 + 포즈 F01
  → 프레임 1장

포즈 F02, F03, F04도 한 장씩 반복
  → PixelPet Studio에서 가져오기·배경 제거·재생
```

## 1. 원본 마스코트 점검

다음 조건에 가까운 이미지를 준비하세요.

- 전신이 잘리지 않고 선명함
- 얼굴, 대표 색, 의상, 로고, 장식이 가려지지 않음
- 캐릭터가 한 명만 있음
- 기관이나 권리자로부터 사용할 권한을 확인함
- 가능하면 정면 이미지와 측면 이미지를 각각 준비함

정면 한 장만 있어도 시작할 수 있습니다. 여러 캐릭터가 함께 있는 단체 이미지는 피하세요.

## 2. 바뀌면 안 되는 특징 적기

AI에 보내기 전에 아래 네 줄을 직접 채우세요. 이 메모가 캐릭터가 프레임마다 달라지는 것을 줄여 줍니다.

```text
캐릭터 한 줄 설명: [예: 둥근 파란 몸과 노란 별 안테나가 있는 작은 우주 생물]
반드시 유지할 색: [예: 몸 파랑, 안테나 별 노랑, 눈 진한 남색]
반드시 유지할 형태: [예: 안테나 1개, 팔 2개, 짧은 다리 2개]
반드시 유지할 표식·의상: [예: 가슴의 흰색 원형 표식]
```

모르는 HEX 색상 코드를 억지로 쓰지 않아도 됩니다. “밝은 민트색 몸”, “자주색 목도리”처럼 눈으로 구분되는 표현이면 충분합니다.

## 3. 스타일 레퍼런스 고르기

1. PixelPet Studio에서 **생성 가이드**를 엽니다.
2. **스타일 선택**에서 원하는 스타일 하나를 누릅니다.
3. **선택한 스타일 레퍼런스 저장**을 누릅니다.

처음이라면 작은 펫에 잘 맞는 64×64 스타일을 권장합니다. 일부 스타일은 96×96입니다. 앱에 표시된 캔버스 크기를 기억하고 같은 펫의 모든 프레임에서 스타일과 크기를 바꾸지 마세요.

스타일 레퍼런스는 색이나 캐릭터 형태를 복사하기 위한 이미지가 아닙니다. 픽셀 크기, 외곽선, 명암 방식만 전달합니다. 오리지널 예시 펫의 원본 이미지는 사용자 캐릭터와 섞일 수 있으므로 첨부하지 마세요.

## 4. 기준 픽셀 마스터 한 장 만들기

### 첨부 순서

AI의 새 대화를 열고 다음 순서로 첨부합니다.

1. `REFERENCE 1`: 내 원본 마스코트
2. `REFERENCE 2`: 앱에서 저장한 스타일 레퍼런스

두 이미지가 어떤 역할인지 메시지 안에도 적어 주세요. 첨부 순서가 화면에서 바뀌었다면 “첫 번째로 첨부한 원본”처럼 분명히 지칭합니다.

### 복사해서 쓰는 기준 마스터 프롬프트

대괄호 부분을 내 캐릭터에 맞게 바꿔 붙여 넣으세요.

```text
REFERENCE 1은 정체성을 바꾸면 안 되는 원본 마스코트다.
REFERENCE 2는 픽셀 크기, 외곽선, 색 덩어리와 명암 방식만 참고하는 스타일 자료다.
REFERENCE 2의 색이나 도형, 캐릭터 형태는 복사하지 않는다.

REFERENCE 1의 동일한 캐릭터를 작은 데스크톱 펫용 픽셀아트로 다시 그려라.

캐릭터 한 줄 설명: [여기에 작성]
반드시 유지할 색: [여기에 작성]
반드시 유지할 형태: [여기에 작성]
반드시 유지할 표식·의상: [여기에 작성]

조건:
- 캐릭터 전신 하나만 중앙에 배치
- 앱에서 선택한 [64×64 또는 96×96] 정사각형 결과에 맞는 또렷한 하드 픽셀
- 같은 크기의 픽셀, 제한된 팔레트, 일정한 외곽선
- 얼굴과 대표 색, 로고, 의상, 고유 장식을 원본과 같게 유지
- 글자, 캡션, 프레임 번호, 워터마크, 소품, 바닥선, 외부 그림자 금지
- 안티앨리어싱, 블러, 사진 같은 질감 금지
- 배경은 투명하게 만들고, 불가능하면 캐릭터에 없는 완전한 단색 한 가지 사용
- 설명이나 비교판 없이 이미지 한 장만 출력

새 캐릭터를 창작하거나 특정 게임·작가·프랜차이즈의 화풍을 모사하지 마라.
```

### 결과 확인

아래 질문이 모두 “예”이면 기준 마스터로 승인합니다.

- 원본을 본 사람이 같은 캐릭터라고 알아볼 수 있는가?
- 얼굴, 대표 색, 로고, 의상, 장식의 개수와 위치가 맞는가?
- 귀, 꼬리, 팔, 다리가 임의로 늘거나 사라지지 않았는가?
- 전신이 잘리지 않았는가?
- 캐릭터가 한 명만 있는가?
- 픽셀 크기와 외곽선이 일정한가?

승인한 이미지를 `canonical-master.png`처럼 이름 붙여 따로 보관하세요. 이후 포즈 생성에서 이 이미지가 가장 중요한 기준입니다.

## 5. 대기 프레임을 한 장씩 만들기

### 포즈 이미지 저장

1. PixelPet Studio의 **생성 가이드**에서 **대기**를 선택합니다.
2. F01, F02, F03, F04 이미지를 각각 눌러 저장합니다.
3. 어느 파일이 몇 번째인지 헷갈리지 않게 같은 폴더에 둡니다.

### 프레임마다 첨부할 이미지

새 프레임을 만들 때마다 아래 순서를 유지합니다.

1. `REFERENCE 1`: 승인한 기준 픽셀 마스터
2. `REFERENCE 2`: 기준 마스터 때 사용한 같은 스타일 레퍼런스
3. `REFERENCE 3`: 지금 만들 순번의 포즈 레퍼런스 한 장
4. `REFERENCE 4`: 원본 마스코트. 기준 이미지에서 가려진 특징을 확인해야 할 때만 추가

F01을 만들 때는 F01 포즈만 첨부하고, F02를 만들 때는 F02 포즈로 바꿉니다. 네 포즈를 한꺼번에 첨부하지 마세요.

### 복사해서 쓰는 포즈 프롬프트

```text
REFERENCE 1의 승인된 픽셀 캐릭터를 그대로 유지하고 포즈만 바꿔라.
REFERENCE 2는 같은 픽셀 스타일 규칙만 확인하는 자료다.
REFERENCE 3은 현재 프레임의 관절, 무게 중심과 발 위치만 참고한다.
포즈 자료의 회색 도형, 색, 비율, 관절점은 결과에 복사하지 않는다.

현재 작업: 대기 동작 [F01/F02/F03/F04 중 하나]

고정 조건:
- REFERENCE 1의 얼굴 픽셀, 실루엣, 대표 색, 의상, 로고와 장식을 유지
- 기준 마스터와 같은 [64×64 또는 96×96] 정사각형 캔버스와 동일한 캐릭터 크기 유지
- 모든 대기 프레임의 발 기준선 유지
- 외곽선 굵기와 빛 방향 유지
- 현재 프레임 한 장만 출력
- 다른 프레임, 스프라이트시트, 비교판, 글자, 번호 금지
- 배경은 투명하게 만들고, 불가능하면 캐릭터에 없는 완전한 단색 한 가지 사용
- 블러, 안티앨리어싱, 반투명 테두리 금지

새로 디자인하지 말고 관절 주변의 필요한 픽셀만 최소한으로 바꿔라.
```

결과는 아래처럼 순번을 앞에 맞춰 저장합니다.

```text
idle-01.png
idle-02.png
idle-03.png
idle-04.png
```

## 6. GPT에서 작업할 때

1. 이미지 생성과 파일 첨부가 가능한 새 대화를 엽니다.
2. 필요한 레퍼런스를 순서대로 첨부합니다.
3. 프롬프트를 같은 메시지에 넣습니다.
4. 결과 이미지를 원본 크기로 저장합니다.
5. 결과가 틀렸다면 새 디자인을 요청하지 말고 아래의 최소 수정 문구를 사용합니다.

```text
현재 결과를 새로 디자인하지 말고 다음 항목만 최소 수정해라:
- [예: 꼬리 2개를 원본과 같은 1개로 수정]
- [예: 목도리 색을 기준 이미지와 같은 민트색으로 복원]
그 외 얼굴, 포즈, 픽셀 크기, 팔레트와 캔버스는 그대로 유지한다.
이미지 한 장만 출력한다.
```

## 7. Gemini에서 작업할 때

1. 이미지 생성과 이미지 첨부를 지원하는 대화를 엽니다.
2. 첨부 후 메시지에서 `REFERENCE 1`, `REFERENCE 2`, `REFERENCE 3`의 역할을 다시 적습니다.
3. 결과를 한 장만 요청합니다.
4. 내려받은 이미지가 WebP여도 PixelPet Studio에 넣을 수 있지만, 가능하면 PNG로 보관합니다.
5. 앱에 넣는 한 장은 20MB·전체 4MP 이하이고 가로와 세로가 각각 4096px 이하여야 합니다. 보통 생성 AI의 1024×1024 결과는 그대로 사용할 수 있습니다.
6. 여러 장이 한 그림에 합쳐졌다면 아래 문구로 다시 요청합니다.

```text
콜라주나 스프라이트시트를 만들지 마라.
현재 포즈 한 장만 정사각형 단일 이미지 파일로 다시 출력하라.
```

## 8. AI 결과가 완벽히 투명하지 않아도 괜찮습니다

생성 AI가 체커보드 무늬를 배경으로 그리거나 흰 배경을 남길 수 있습니다. 투명한 것처럼 보이는 체커보드가 실제 픽셀로 그려졌는지도 확인하세요.

PixelPet Studio의 **배경 제거**가 마지막 알파 처리를 담당합니다. 배경 제거가 잘되도록 다음을 지키면 좋습니다.

- 캐릭터와 확실히 다른 단색 배경
- 복잡한 장면이나 바닥 그림자 없음
- 전신과 부속물이 캔버스 안에 있음
- 캐릭터 가장자리와 배경의 색 차이가 큼

## 9. 걷기와 다른 동작 추가

대기 4장으로 첫 펫 실행에 성공한 다음 확장하세요.

| 동작 | 필요한 장수 | 용도 |
|---|---:|---|
| 대기 | 4 | 가만히 있을 때. 먼저 만들기 |
| 걷기 | 8 | 화면을 이동할 때 |
| 점프 | 6 | 도약과 착지 |
| 잠자기 | 4 | 쉬는 루프 |
| 반응 | 6 | 클릭했을 때의 짧은 반응 |

동작이 달라도 기준 픽셀 마스터와 스타일 레퍼런스는 바꾸지 않습니다.

더 정밀한 변수와 전체 프롬프트 체계가 필요하면 [고급 프롬프트 가이드](../prompting/README.md)를 참고하세요.
