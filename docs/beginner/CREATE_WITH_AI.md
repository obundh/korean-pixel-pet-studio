# GPT·Gemini로 움직이는 픽셀 펫 만들기

처음 필요한 것은 **내 마스코트 이미지 한 장**입니다.

> - **첫 번째 AI 요청:** 원본 1장 첨부
> - **두 번째 AI 요청:** 픽셀 마스터 1장 + 대기 포즈 가이드 1장 첨부
> - **PixelPet Studio:** 완성된 4칸 시트 1장 가져오기

스타일 이미지는 따로 첨부하지 않습니다. 포즈 이미지 4장도 따로 저장하지 않습니다.

```text
내 원본 1장
  → AI 요청 1: 기준 픽셀 마스터 1장

픽셀 마스터 1장 + 앱의 대기 포즈 가이드 1장
  → AI 요청 2: 가로 4칸 시트 1장

가로 4칸 시트 1장
  → PixelPet Studio: 분할 · 배경 제거 · 정렬 · 재생
```

GPT와 Gemini의 버튼 위치는 바뀔 수 있습니다. 버튼 모양보다 **첨부 이미지 수**와 **첨부 순서**를 확인하세요.

## AI와 앱이 나누어 하는 일

| 작업 | 담당 |
|---|---|
| 원본을 기본 픽셀 스타일로 다시 그리기 | GPT, Gemini 같은 이미지 생성 AI |
| 같은 캐릭터의 대기 포즈 4개 만들기 | 이미지 생성 AI |
| 4칸 시트를 프레임으로 나누기 | PixelPet Studio |
| 배경 제거와 공통 좌표 정리 | PixelPet Studio의 로컬 처리 |
| 재생, 저장, 데스크톱 실행 | PixelPet Studio |

PixelPet Studio는 대화형 이미지 생성을 내장하지 않습니다. 외부 AI에 올린 이미지에는 그 서비스의 이용약관과 데이터 정책이 적용됩니다.

기관 마스코트, 로고, 브랜드 이미지는 **AI 입력·변형·공개·재배포 권한**을 각각 확인하세요.

## 1. 원본 한 장 고르기

다음 조건에 가까운 이미지 한 장이면 됩니다.

- 캐릭터 전신이 선명하게 보임
- 얼굴, 대표 색, 의상, 로고와 장식이 가려지지 않음
- 캐릭터가 한 명만 있음
- 사용할 권한을 확인함

측면 이미지나 여러 각도 사진은 처음에는 필요하지 않습니다. 정면 또는 캐릭터 특징이 가장 잘 보이는 이미지 한 장을 고르세요.

## 2. 바뀌면 안 되는 특징 적기

아래 네 줄만 채우세요. HEX 색상 코드는 몰라도 됩니다.

```text
캐릭터 한 줄 설명: [예: 둥근 파란 몸과 노란 별 안테나가 있는 작은 우주 생물]
반드시 유지할 색: [예: 몸 파랑, 안테나 별 노랑, 눈 진한 남색]
반드시 유지할 형태: [예: 안테나 1개, 팔 2개, 짧은 다리 2개]
반드시 유지할 표식·의상: [예: 가슴의 흰색 원형 표식]
```

## 3. 첫 번째 AI 요청: 픽셀 마스터 만들기

### 첨부하는 이미지

**원본 마스코트 1장만 첨부합니다.**

스타일 이미지나 포즈 이미지는 첨부하지 마세요. 기본 스타일 규칙은 아래 프롬프트에 들어 있습니다.

### 복사 프롬프트

대괄호 부분만 내 캐릭터에 맞게 바꾸세요.

```text
REFERENCE 1은 정체성을 바꾸면 안 되는 원본 마스코트다.
REFERENCE 1의 동일한 캐릭터를 작은 데스크톱 펫용 기본 픽셀아트로 다시 그려라.

캐릭터 한 줄 설명: [여기에 작성]
반드시 유지할 색: [여기에 작성]
반드시 유지할 형태: [여기에 작성]
반드시 유지할 표식·의상: [여기에 작성]

기본 픽셀 스타일 규칙:
- 64×64 설계 격자에 어울리는 크고 또렷한 하드 픽셀
- 16색 안팎의 제한된 팔레트
- 1~2픽셀 두께로 보이는 일정한 어두운 외곽선
- 색상마다 밝음, 기본, 그림자의 단순한 2~3단 명암
- 한 방향에서 오는 단순한 빛
- 안티앨리어싱, 블러, 디더링과 사진 같은 질감 금지

출력 조건:
- 캐릭터 전신 하나만 중앙에 배치
- 얼굴, 대표 색, 로고, 의상과 고유 장식을 원본과 같게 유지
- 글자, 번호, 워터마크, 소품, 바닥선과 외부 그림자 금지
- 배경은 캐릭터에 전혀 쓰이지 않은 완전한 단색 한 가지
- 설명이나 비교판 없이 이미지 한 장만 출력

새 캐릭터를 창작하거나 특정 게임, 작가 또는 프랜차이즈의 화풍을 모사하지 마라.
```

### 저장 전 확인

- 원본을 아는 사람이 같은 캐릭터라고 알아볼 수 있는가?
- 얼굴, 대표 색, 로고, 의상과 장식이 맞는가?
- 귀, 꼬리, 팔과 다리가 임의로 늘거나 사라지지 않았는가?
- 전신이 잘리지 않았는가?
- 픽셀이 또렷한가?

모두 맞으면 `canonical-master.png`로 저장합니다.

## 4. 앱에서 대기 포즈 가이드 한 장 저장하기

1. PixelPet Studio의 **생성 가이드**를 엽니다.
2. **대기 포즈 가이드 1장 저장**을 누릅니다.
3. 저장된 PNG를 찾습니다.

**4컷이 한 파일에 들어 있습니다.** F01, F02, F03, F04를 따로 저장할 필요가 없습니다.

이 가이드는 캐릭터 디자인을 정하는 스타일 이미지가 아닙니다. 네 포즈의 순서와 움직임만 알려 줍니다.

## 5. 두 번째 AI 요청: 대기 4칸 시트 만들기

### 첨부하는 이미지

아래 **두 장만** 순서대로 첨부합니다.

1. `REFERENCE 1`: 승인한 픽셀 마스터 1장
2. `REFERENCE 2`: 앱에서 저장한 대기 포즈 가이드 1장

원본 마스코트, 별도 스타일 이미지, 개별 포즈 4장은 다시 첨부하지 않습니다.

### 복사 프롬프트

```text
REFERENCE 1은 승인된 픽셀 캐릭터다. 얼굴, 실루엣, 대표 색, 의상, 로고, 장식과 픽셀 스타일을 그대로 유지하라.
REFERENCE 2는 왼쪽부터 시간순인 대기 포즈 4컷 가이드다. 포즈의 순서와 움직이는 부분만 참고하라.
REFERENCE 2의 캐릭터 모양, 회색 도형, 색과 비율은 복사하지 마라.

REFERENCE 1과 동일한 캐릭터의 실제 대기 애니메이션 포즈 4개를 한 장에 만들어라.

출력 배치:
- 완전히 같은 너비와 높이의 4칸을 가로 한 줄로 배치
- 왼쪽부터 F01, F02, F03, F04 시간순
- 칸 사이 선, 테두리, 간격 띠, 글자와 프레임 번호 없음
- 각 칸에 캐릭터 한 명씩 배치
- 네 칸 모두 같은 카메라, 크기, 몸 중심과 발 기준선

움직임:
- F01: 중립 대기
- F02: 가슴, 손, 귀 또는 장식이 조금 올라가는 들숨
- F03: 중립으로 돌아오는 연결 포즈
- F04: 눈꺼풀, 꼬리 끝 또는 장식이 조금 움직이는 날숨
- 팔, 꼬리, 귀, 눈 또는 장식의 필요한 픽셀을 실제로 바꿀 것
- 캐릭터 전체를 확대, 축소, 늘이거나 납작하게 만들지 말 것
- F04에서 F01로 자연스럽게 이어질 것

고정 조건:
- REFERENCE 1의 기본 픽셀 크기, 팔레트, 외곽선과 빛 방향 유지
- 전신과 부속물이 각 칸 안에 들어감
- 바닥 그림자, 효과선, 소품, 추가 캐릭터와 워터마크 없음
- 네 칸 전체에 캐릭터에 없는 완전한 단색 배경 한 가지
- 안티앨리어싱, 블러와 반투명 테두리 없음

설명 없이 가로 4칸 이미지 한 장만 출력하라.
```

### 저장 전 확인

- 한 줄에 정확히 네 포즈가 있는가?
- 네 칸의 너비와 높이가 같은가?
- 칸 사이 선, 번호와 글자가 없는가?
- 캐릭터 크기와 발 기준선이 비슷한가?
- 얼굴, 색, 로고와 장식이 유지되는가?
- 마지막 포즈에서 첫 포즈로 자연스럽게 이어지는가?

결과를 `idle-sheet.png`로 저장합니다.

## 6. PixelPet Studio에서 시트 한 장 처리하기

1. **프레임 가져오기**를 엽니다.
2. 기본 화면의 **대기 포즈 시트 한 장 가져오기**를 누릅니다.
3. `idle-sheet.png` 한 장을 선택합니다.
4. “대기 시트를 4컷으로 나눴어요”와 `4/4컷`이 보이는지 확인합니다.
5. 순서는 **움직임 확인** 화면의 재생으로 확인합니다.
6. **이 동작 한 번에 정리**를 누릅니다.
7. **움직임 확인**에서 4 FPS로 재생합니다.

앱은 시트를 4등분하고 배경을 제거합니다. 모든 포즈에는 같은 캔버스와 배율을 적용합니다. 이 과정에서 이미지는 외부 서버로 전송되지 않습니다.

### 시트 파일 제한

- PNG, JPG 또는 WebP
- 최대 20MB
- 전체 4MP 이하
- 가로와 세로가 각각 4096px 이하
- 가로 길이가 4로 정확히 나누어짐

예를 들어 3840×960은 사용할 수 있습니다. 4096×1024는 4MP를 넘으므로 사용할 수 없습니다.

## 7. 실패 결과 고치기

처음부터 다시 만들기보다 틀린 부분만 말하세요.

### 2×2 콜라주가 나왔을 때

```text
현재 캐릭터 디자인과 네 포즈는 유지하라.
2×2가 아니라 같은 너비의 4칸을 가로 한 줄로 다시 배치하라.
칸 사이 선, 번호, 글자와 간격 띠는 넣지 마라.
```

### 프레임마다 다른 캐릭터처럼 보일 때

```text
REFERENCE 1의 얼굴, 몸 비율, 대표 색, 로고, 의상과 장식 개수를 네 칸 모두 똑같이 복구하라.
포즈에 필요한 팔, 꼬리, 귀, 눈 또는 장식의 움직임만 남겨라.
```

### 마지막에서 처음으로 돌아갈 때 튈 때

```text
F01~F03은 그대로 유지하라.
F04를 F01과 거의 같은 중립 자세로 수정하되 눈 또는 장식의 작은 변화만 남겨라.
F04에서 F01로 이어질 때 몸 중심, 크기와 발 기준선이 움직이지 않게 하라.
```

### 글자나 선이 들어갔을 때

```text
네 포즈와 단색 배경은 유지하라.
칸 사이 선, 프레임 번호, 글자와 바깥 테두리만 제거하라.
```

## 8. 배경은 단색이어도 됩니다

생성 AI가 투명 배경을 만들지 못해도 괜찮습니다. 아래 조건이면 앱이 처리하기 쉽습니다.

- 캐릭터에 쓰이지 않은 단색 한 가지
- 네 칸 모두 같은 배경색
- 복잡한 장면과 바닥 그림자 없음
- 캐릭터와 배경의 색 차이가 큼

회색 체크무늬를 그리게 하지 마세요. 실제 체크무늬 픽셀은 투명 배경이 아닙니다.

## 9. 고급 선택사항

첫 대기 펫을 완성한 뒤에만 사용하세요.

- 측면 또는 뒷면 원본 추가
- 별도 스타일 레퍼런스 사용
- F01~F04 개별 포즈 파일 사용
- 걷기, 점프, 잠자기, 반응 동작 추가
- 96×96 캔버스나 다른 팔레트 사용

이 항목은 모두 선택사항입니다. 기본 제작에는 필요하지 않습니다.

정밀한 변수와 전체 프롬프트 체계는 [고급 프롬프트 가이드](../prompting/README.md)를 참고하세요.
