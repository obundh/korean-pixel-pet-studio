# PixelPet Studio 화면 따라 하기

이 문서는 앱에서 보이는 버튼 이름을 기준으로 설명합니다. 공식 샘플과 권장 흐름은 **4칸 가로 포즈 시트 → 자동 분할 → 이 동작 한 번에 정리 → 4 FPS 재생**입니다.

## 화면의 기본 구조

- 위쪽 가운데: 프로젝트 이름
- 위쪽 오른쪽 **불러오기**: 저장한 `.pixelpet` 프로젝트 열기
- 위쪽 오른쪽 **저장**: 현재 프로젝트 저장
- 왼쪽: 제작 과정 1~5단계
- 오른쪽 큰 영역: 현재 단계의 작업 화면
- 왼쪽 아래: 가져온 프레임과 배경 제거 완료 개수

프로젝트 이름을 먼저 알아보기 쉽게 바꾸면 저장 파일 이름을 찾기 쉽습니다.

## 보조 기능: 이미지 한 장으로 빠르게 시험하기

이미 픽셀 캐릭터 이미지가 한 장뿐이고 앱 실행만 빨리 시험하려면 이 기능을 사용하세요.

빠른 만들기는 **생성 가이드**에서 현재 선택한 스타일의 캔버스 크기를 따릅니다. 기본 선택은 64×64이며 일부 스타일은 96×96입니다. 원하는 크기가 있다면 빠른 만들기 전에 스타일을 먼저 선택하세요.

1. 왼쪽 **배경 제거** 단계로 이동합니다.
2. **이미지 한 장으로 자동 완성** 카드와 **추천** 표시를 찾습니다.
3. 카드 안의 **이미지 한 장 고르기**를 누릅니다.
4. PNG, JPG 또는 WebP 이미지 한 장을 선택합니다.
5. 처리가 끝날 때까지 창을 닫거나 버튼을 다시 누르지 않습니다.

앱은 다음 작업을 자동으로 합니다.

1. 기기 안의 AI 모델로 배경 제거
2. 캐릭터 비율을 유지한 채 선택한 스타일의 투명 캔버스에 맞춤. 기본 예시는 64×64이고 일부 스타일은 96×96
3. 픽셀 보간 없이 또렷하게 정규화
4. 같은 그림을 `0px → 위로 1px → 위로 1px → 0px`로 옮긴 `idle` 프레임 4장 구성
5. 네 프레임을 대기 슬롯에 넣고 첫 프레임 선택

빠른 만들기는 새로운 걷기나 점프 포즈를 그리지 않습니다. 전체 이미지를 늘이거나 찌그러뜨리지 않고 정수 1px만 움직이는 **무왜곡 bob**입니다. 팔·다리·표정·꼬리가 실제로 바뀌는 애니메이션은 아니므로 공식 샘플과 같은 결과를 원하면 아래의 포즈 시트 흐름을 사용하세요.

### 정상이라면

- 대기 프레임 수가 `4/4`로 보입니다.
- 처리된 프레임에는 배경 제거 완료 표시가 보입니다.
- 체크무늬 위에서 캐릭터 바깥 배경이 투명하게 보입니다.
- **움직임 확인**에서 캐릭터 그림 전체가 4 FPS로 1px 올라갔다 내려옵니다.

캐릭터 일부가 사라지거나 배경이 남으면 [배경 제거 문제](TROUBLESHOOTING.md#배경-제거)를 확인하세요.

## STEP 01 · 생성 가이드

이 단계는 GPT 또는 Gemini에 함께 보낼 스타일과 포즈 자료를 고르는 곳입니다.

### 1. 예시 펫 보기

**5가지 완성 예시**는 결과의 크기와 느낌을 살펴보기 위한 데모입니다. 내 마스코트를 생성할 때 예시 펫 원본을 함께 첨부하면 캐릭터 특징이 섞일 수 있으므로 사용하지 마세요.

### 2. 스타일 선택

1. **스타일 선택** 목록에서 하나를 누릅니다.
2. 선택 표시와 캔버스 크기, 색상 수를 확인합니다.
3. **선택한 스타일 레퍼런스 저장**을 누릅니다.

한 프로젝트에서는 모든 프레임에 같은 스타일을 사용하세요.

### 3. 동작과 프레임 순서

1. **대기**, **걷기**, **점프**, **잠자기**, **반응** 중 하나를 누릅니다.
2. F01부터 순서대로 포즈를 확인합니다.
3. 포즈 시트 생성에 참고할 F01부터 마지막 프레임까지 저장합니다.

포즈 이미지는 회색 캐릭터를 복사하기 위한 것이 아니라 관절과 무게 중심을 전달하기 위한 자료입니다.

### 4. 프롬프트 사용

**프롬프트 복사**를 누른 뒤 AI 대화에 붙여 넣습니다. 기준 픽셀 마스터를 먼저 승인하고, 처음에는 대기 F01~F04를 왼쪽부터 배치한 4칸 가로 시트 한 장을 만드세요. 자세한 첨부 순서와 시트 프롬프트는 [AI로 이미지 만들기](CREATE_WITH_AI.md)에 있습니다.

## STEP 02 · 프레임 가져오기

AI에서 만든 가로 포즈 시트를 자동으로 나누고, 동작 전체의 배경과 좌표를 한 번에 정리하는 단계입니다.

### 파일 준비

- 지원 형식: PNG, JPG, WebP
- 한 장당 최대 크기: 20MB
- 해상도 제한: 전체 4MP(400만 픽셀), 가로와 세로 각각 최대 4096px
- 권장 파일명: `idle-sheet.png`, `walk-sheet.png`
- 시트는 한 줄이며 각 칸의 너비와 높이가 같아야 함
- 시트 가로 길이는 선택한 동작의 슬롯 수로 정확히 나누어져야 함

| 선택한 동작 | 시트 칸 수 | 앱의 정리 후 기본 FPS |
|---|---:|---:|
| 대기 | 4칸 | 4 FPS |
| 걷기 | 8칸 | 8 FPS |
| 점프 | 6칸 | 8 FPS |
| 잠자기 | 4칸 | 4 FPS |
| 반응 | 6칸 | 8 FPS |

### 가장 쉬운 방법: 포즈 시트 한 장 가져오기

1. 위쪽에서 **대기** 동작 탭을 선택합니다.
2. **포즈 시트 한 장 가져오기**를 누릅니다.
3. 왼쪽부터 F01, F02, F03, F04가 들어 있는 한 줄 시트를 선택합니다.
4. 앱이 시트를 똑같은 너비로 4등분해 슬롯 01~04에 넣습니다.
5. 슬롯을 한 장씩 눌러 왼쪽→오른쪽 순서가 맞는지 확인합니다.
6. **이 동작 한 번에 정리**를 누릅니다.
7. “공통 좌표 정리 완료”가 보일 때까지 기다립니다.

**이 동작 한 번에 정리**는 다음을 처리합니다.

1. 이미 투명한 PNG인지, 단색 배경인지, 일반 배경인지 확인
2. 단색 배경은 색 번짐까지 직접 제거하고 일반 배경은 로컬 AI로 제거
3. 모든 포즈의 캐릭터 범위를 함께 계산
4. 프레임마다 따로 확대하지 않고 넓고 안정적인 몸통 행을 기준으로 작은 좌우 드리프트만 제한적으로 보정한 뒤, 세로 위치를 유지하면서 하나의 공통 캔버스·배율로 정렬
5. 선택한 동작의 기본 FPS 설정

이 작업은 시트 안의 포즈를 새로 그리지 않습니다. AI가 만든 실제 포즈 픽셀은 유지하고 분할·투명화·정렬만 담당합니다.

### 개별 파일을 넣는 방법

1. 위쪽에서 동작 탭을 선택합니다.
2. 빈 슬롯의 **이미지 놓기**를 누릅니다.
3. 그 순번에 맞는 이미지 한 장을 선택합니다.

파일을 빈 슬롯 위로 끌어다 놓아도 됩니다.

여러 파일이 이미 따로 있다면 **개별 포즈 여러 장 가져오기**로 빈 슬롯에 넣을 수도 있습니다. 파일 이름은 `idle-01.png`, `idle-02.png`처럼 두 자리 순번을 사용하세요.

운영체제가 파일명을 정렬하는 방식이 다를 수 있으므로 여러 파일을 선택한 뒤에는 슬롯 순서를 반드시 눈으로 확인합니다.

### 잘못 넣었을 때

- 다른 이미지로 바꾸기: 슬롯 아래 **교체**
- 슬롯 비우기: 휴지통 아이콘
- 다음 단계에서 편집할 이미지 선택: 이미지 미리보기 클릭

### 정상이라면

- 동작 탭에 `4/4`, `8/8`처럼 채운 수가 표시됩니다.
- 슬롯마다 올바른 순번의 캐릭터가 보입니다.
- 선택한 슬롯에 강조 테두리가 표시됩니다.
- 일괄 정리 후 상태에 **공통 좌표 정리 완료**가 표시됩니다.
- 대기 동작을 정리했다면 프레임 속도가 4 FPS로 맞춰집니다.

## STEP 03 · 배경 제거

선택한 프레임의 배경을 수동으로 다시 처리하는 단계입니다. STEP 02에서 **이 동작 한 번에 정리**를 완료했다면 모든 프레임이 이미 투명화·공통 정렬되어 있으므로 결과 확인이나 문제 프레임 재처리에 사용하세요.

1. 왼쪽 **처리할 프레임** 목록에서 첫 이미지를 누릅니다.
2. 오른쪽의 ORIGINAL과 RESULT를 확인합니다.
3. **배경 제거**를 누릅니다.
4. 진행률이 100%가 될 때까지 기다립니다.
5. RESULT에서 체크무늬가 캐릭터 주위에 보이는지 확인합니다.
6. 다음 프레임을 선택하고 반복합니다.

첫 실행은 로컬 AI 모델을 메모리에 올리기 때문에 더 오래 걸릴 수 있습니다. 이미지는 외부 서버로 전송되지 않습니다.

### 결과가 마음에 들지 않을 때

- **원본 복원**: 해당 슬롯을 처음 가져온 이미지로 되돌림
- **다시 제거**: 같은 원본에서 배경 제거 다시 실행
- 원본 자체를 바꾸려면 **프레임 가져오기**로 돌아가 **교체**

### 정상이라면

- 처리한 프레임에 초록 체크가 표시됩니다.
- 왼쪽 위 완료 수가 `4/4`처럼 보입니다.
- RESULT의 캐릭터 바깥이 체크무늬로 보입니다.

펫으로 사용할 모든 프레임에 완료 표시가 있는지 확인하세요. 여러 장을 개별 처리하기보다 STEP 02의 **이 동작 한 번에 정리**를 먼저 사용하는 편이 프레임마다 따로 잘리거나 확대되는 문제를 막을 수 있습니다. 입력 시트에 그려진 발 위치 차이는 그대로 유지되므로 AI 생성 단계에서 발 기준선을 맞춰야 합니다.

## STEP 04 · 움직임 확인

1. 위쪽에서 확인할 동작을 선택합니다.
2. 재생 버튼으로 움직임을 켜거나 멈춥니다.
3. 프레임 아래의 점을 눌러 한 장씩 확인합니다.
4. **프레임 속도**를 조절합니다.
5. **화면 배율**을 조절합니다.

일괄 정리 후 앱이 넣는 기본값은 다음과 같습니다.

- 대기·잠자기: 4 FPS
- 걷기·점프·반응: 8 FPS
- 화면 배율: 3×

프레임 속도는 동작별로 따로 저장됩니다. 대기 탭에서 4 FPS를 정한 뒤 걷기 탭을 8 FPS로 바꿔도 대기 속도는 그대로 유지됩니다. 숫자보다 눈으로 자연스럽게 보이는지가 중요합니다.

### 확인할 것

- 얼굴과 대표 장식이 프레임마다 바뀌지 않음
- 발이나 배의 기준선이 갑자기 튀지 않음
- 전체 캐릭터 크기가 갑자기 커지거나 작아지지 않음
- 배경이나 흰 테두리가 보이지 않음
- 프레임 순서가 자연스럽게 이어짐
- 마지막 프레임에서 첫 프레임으로 돌아갈 때도 갑자기 튀지 않음
- 한 장 전체가 늘거나 납작해지는 대신 팔·꼬리·눈·장식처럼 의도한 부분이 실제로 움직임

문제가 있는 한 장만 기억한 뒤 **프레임 가져오기**로 돌아가 교체할 수 있습니다.

## STEP 05 · 펫 완성

### 데스크톱에서 실행

1. 실행할 동작 탭을 선택합니다.
2. **데스크톱에서 실행**을 누릅니다.
3. 화면 위에 작은 펫 창이 나타나는지 확인합니다.

펫을 끄려면 앱의 **데스크톱 펫 종료**를 누릅니다. Studio 앱을 닫기 전에 프로젝트부터 저장하세요.

### 프로젝트 저장

**프로젝트 저장**은 가장 먼저 해야 할 보관 작업입니다.

- 확장자: `.pixelpet`
- 포함 내용: 가져온 원본, 투명화 결과, 프레임 순서, FPS, 화면 배율
- 용도: 나중에 **불러오기**로 다시 열어 계속 편집

위쪽 **저장** 버튼도 같은 프로젝트 저장 기능입니다. 처음 저장할 때 위치를 물어보고, 이후에는 같은 파일에 변경 내용을 저장합니다. 다른 사본을 만들려면 **펫 완성** 화면의 **다른 이름으로**를 사용합니다.

### PNG 내보내기

**PNG 내보내기**는 동작을 행별로 배치한 스프라이트시트를 만듭니다. 게임이나 웹 제작에 사용할 때 선택합니다. 이 PNG만으로는 PixelPet Studio 편집 상태를 다시 불러올 수 없으므로 `.pixelpet`도 함께 보관하세요.

### JSON 내보내기

개발 도구와 데이터를 연결할 때 사용하는 고급 기능입니다. 처음 사용하는 분은 건너뛰어도 됩니다.

## 기존 프로젝트 다시 열기

1. 앱 위쪽 **불러오기**를 누릅니다.
2. `.pixelpet` 파일을 선택합니다.
3. 프로젝트 이름과 프레임이 돌아왔는지 확인합니다.
4. 필요한 슬롯을 교체하거나 새 동작을 추가합니다.
5. 위쪽 **저장**을 누릅니다.

`.pixelpet` 파일을 메모장으로 고치거나 확장자를 임의로 바꾸지 마세요.
